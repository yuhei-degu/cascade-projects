⌨️ 最初のGitセットアップ（1回だけ）

PowerShell
# 名前とメールを設定
PS> git config --global user.name "あなたの名前"
PS> git config --global user.email "your@email.com"
PowerShell
# プロジェクトフォルダでGit開始
PS> cd C:\Users\名前\Documents\my-app
PS> git init
# → "Initialized empty Git repository" でOK！
PowerShell
# 変更を保存（セーブポイント作成）
PS> git add .
PS> git commit -m "✨ 最初のファイルを追加"
# 過去に戻れるセーブポイント完成！
💡 コマンドが怖い？CursorのGUI操作でOK

左サイドバーの「Source Control」（分岐マーク）をクリックすれば、ボタン操作でGitが使えます。

AIへの上手な伝え方

「何をどう伝えるか」で結果が劇的に変わります。実例で学ぼう。

✅ 伝わりやすい例

HTMLファイル1本で動く、画面中央に赤いドット（直径20px）を表示するアプリ。背景は黒。スライダーでサイズ変更、カラーピッカーで色変更できるようにして。
🤖 AI
了解です！index.htmlを作成します。黒背景・中央の赤ドット・サイズスライダー・カラーピッカーを実装します。
📐
具体的な数字・色

「いい感じ」より「黒背景・白文字・角丸12px・パディング16px」のように数値・色で指定する

🎯
1回1件

一度に10個頼まず、1つ確認したら次。特に初心者のうちは小分けにする方が早い

📋
エラーをそのまま貼る

「動かない」だけでなくエラーメッセージを丸ごとコピーして渡す。AIが即座に原因を特定できる

🔄
反復する

「ちょっと違う、これをこう直して」と繰り返すのが正しい使い方。1回で完璧を求めない

FAQ
よくある疑問

不安を全部解消しよう。

全く問題ありません。AIがコードを書いてくれるので、あなたは「何を作りたいか」を日本語で伝えるだけです。英語のエラーメッセージもそのままAIに貼り付ければ解説してくれます。
AIを使えば最初のアプリは今日中に動かせます。自分でコードを理解して書けるようになるには数ヶ月かかりますが、焦らなくていい。AIと一緒に作りながら学ぶのが最も楽しく確実です。
初心者にはCursorをおすすめします。VS Codeベースで操作感は同じですが、AIとのチャットが統合されており「コードを書かなくてもアプリが作れる」体験が得られます。
