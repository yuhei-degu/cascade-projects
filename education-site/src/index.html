Step by Step
環境構築完全手順書

コピペで進められます。難しいコマンドは一切なし。

✅ インストールチェックリスト

  • 💙
    ① VS Code インストール code.visualstudio.com → Download for Windows → インストーラー実行
  • 🖱️
    ② Cursor インストール cursor.com → Download → インストーラー実行 → Googleアカウントでサインイン
  • 🐙
    ③ Git インストール git-scm.com → Download → すべてデフォルトのままNext連打でOK
  • 🐙
    ④ GitHubアカウント作成 github.com → Sign Up → メールアドレスで登録
  • 🤖
    ⑤ Claude アカウント作成 claude.ai → Googleアカウントでサインアップ（無料）
  • 🎉
    ⑥ 完了！最初のファイルを作ってみよう Cursorを開いて「index.htmlというファイルを作って、Hello Worldを表示して」と打ち込んでみる

⌨️ 最初のGitセットアップ（1回だけ）

Windowsのスタートメニューで「PowerShell」を検索して開き、以下を実行：

名前とメールを設定（GitHubと同じものを）
PS> git config --global user.name "あなたの名前"
PS> git config --global user.email "your@email.com"
プロジェクトフォルダでGitを始める
PS> cd C:\Users\あなたの名前\Documents\my-app
PS> git init
# → "Initialized empty Git repository" と表示されたらOK
変更を保存（セーブ）する
PS> git add .
PS> git commit -m "✨ 最初のファイルを追加"
# これで過去に戻れるセーブポイントができた！
💡 Cursor なら GUI でもできる

左サイドバーの「Source Control」アイコン（分岐マーク）をクリックすると、コマンドなしでGit操作が全部できます。

AI Prompting
AIへの上手な伝え方

AIはすごく賢いけど、伝え方次第で結果が全然変わります。

❌ 伝わりにくい例

"アプリ作って"

"なんかいい感じにして"

"動かない、直して"

✅ 伝わりやすい例

"HTMLファイル1つで動く、画面中央に赤いドットを表示するアプリを作って。背景は黒で、ドットのサイズをスライダーで変えられるようにして"

"ボタンをクリックしても何も起きません。ChromeのDevToolsのConsoleに「Uncaught TypeError」と出ています。コードのどこが問題か教えて"

📐
具体的に

「いい感じ」より「黒背景・赤い文字・角丸ボタン」のように数字・色・形で指定

🎯
1回1件

一度に多くを頼まず、1つずつ確認しながら進める。複雑な変更ほど小分けに

📋
エラーをそのまま貼る

エラーメッセージは丸ごとコピーしてAIに渡す。「動かない」だけより10倍早く解決

🔄
反復する

完璧を求めない。「ちょっと違う、これをこう直して」と繰り返すのが正しい使い方

FAQ
よくある疑問

全く問題ありません。AIがコードを書いてくれるので、あなたは「何を作りたいか」を日本語で伝えるだけです。英語のエラーメッセージもそのままAIに貼り付ければ解説してくれます。
AIを使えば最初のアプリは「今日中」に動かせます。ただし自分でコードを理解して書けるようになるには数ヶ月かかります。でも焦らなくてOK — AIと一緒に作りながら学ぶのが一番楽しく確実です。
初心者には Cursor をおすすめします。VS Codeベースなので操作感は同じですが、AIとのチャットが統合されており「コードを書かなくてもアプリが作れる」体験が得られます。慣れてきたらVS CodeにもAI拡張機能（GitHub Copilot等）を入れて使い比べてみましょう。
HTMLファイルのみで動くWebアプリなら、GitHub Pages を使って完全無料で公開できます。独自ドメイン（〇〇.com）は年間1000円程度かかりますが、github.io のURLなら永久無料です。
自分で使う分・公開する分には基本的に問題ありません。ただし商業利用や他者への販売を考える場合は、使用するAIサービスの利用規約を確認することをおすすめします。個人学習・個人利用の範囲では気にしなくてOKです。
エラーメッセージを丸ごとコピーして、AIに「このエラーが出て動きません」と貼り付けるだけでOKです。AIが原因と解決策を教えてくれます。「エラーを自分で解決しなければ」という焦りは不要。AIはあなたの無限のデバッグパートナーです。
