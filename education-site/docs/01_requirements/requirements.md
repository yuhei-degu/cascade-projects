# 📋 要件定義書 — AI×コード入門 教育資材サイト

**プロジェクト名**: AI Dev Start  
**目的**: PC初心者・プログラミング未経験者がAI×AIエディタで自分のアプリを作れるようにする教育コンテンツ  
**ターゲット**: yuuve と同じ状況の人（PC操作はできるがコードは書けない）  
**公開形式**: GitHub Pages で URL 共有（リンクを送るだけで誰でも見られる）  
**作成日**: 2026-02-22

---

## 1. ユーザーストーリー

| ID | ストーリー | 優先度 |
|----|-----------|--------|
| US-01 | 初心者として、まず何をインストールすればいいか知りたい | 高 |
| US-02 | 初心者として、AIへの効果的な話しかけ方を知りたい | 高 |
| US-03 | 初心者として、Gitで過去に戻る方法を知りたい | 高 |
| US-04 | 初心者として、作ったアプリを無料で公開したい | 高 |
| US-05 | 初心者として、自分の成長ロードマップを把握したい | 中 |
| US-06 | 初心者として、よくある疑問への答えが知りたい | 中 |
| US-07 | 送った人として、リンク1つで全内容が見られる | 高 |

---

## 2. 機能要件

| ID | 機能 | 優先度 |
|----|------|--------|
| F-01 | ヒーローセクション（概要・キャッチコピー） | 高 |
| F-02 | 4ステップの始め方フロー | 高 |
| F-03 | ツール紹介カード（Cursor・Git・GitHub等） | 高 |
| F-04 | 環境構築チェックリスト＋コマンド例 | 高 |
| F-05 | AIへの話しかけ方ガイド（良い例・悪い例） | 高 |
| F-06 | 成長ロードマップ（Phase 1〜∞） | 中 |
| F-07 | FAQ（アコーディオン形式） | 中 |
| F-08 | フッター（外部リンク集） | 低 |
| F-09 | スクロールアニメーション | 低 |

---

## 3. 非機能要件

| 項目 | 要件 |
|------|------|
| 単一ファイル | index.html 1本で完結（外部サーバー不要） |
| 公開方法 | GitHub Pages（設定2クリック） |
| デバイス | PC・スマホ両対応（レスポンシブ） |
| 依存関係 | 外部ライブラリなし（CDN不使用） |
| 読込速度 | 3秒以内（軽量単一ファイル） |

---

## 4. GitHub Pages 公開手順

```
1. GitHubでリポジトリ作成（例: ai-dev-start）
2. education-site/src/index.html をリポジトリ直下に置く
3. Settings → Pages → Source: main branch / root
4. https://ユーザー名.github.io/ai-dev-start/ が公開URL
5. このURLをリンクとして友人に共有
```
