## 🎓 初心者向け学習の進め方

1. **まずアプリを動かしてみる** → src/index.html をブラウザで開く
2. **要件定義を読む** → docs/01_requirements/
3. **設計書を読む** → docs/02_design/
4. **コードを覗いてみる** → src/index.html をVS Codeで開く
5. **少し変えてみる** → 色・文字を変えて動作確認
6. **自分なりに機能を追加してみる！**
