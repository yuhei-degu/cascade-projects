## 🔵 プロンプト①：SEOロング記事の生成

```
あなたはSEOとCVRを最大化するWebメディア編集者です。
以下のテーマで、検索上位を狙うロング記事HTMLを作成してください。

テーマ：
退職前に知らないと損する「傷病手当×失業保険」完全ロードマップ

目的：
・SEO流入獲得（検索上位表示）
・読者の信頼獲得
・メルマガ登録への導線設計

条件：
・誇張表現は禁止
・不正受給を助長しない
・制度は医師の判断が前提であることを明記
・専門的だが分かりやすい文章
・3000〜5000文字
・H1〜H3構造を明確に
・検索キーワードを自然に含める

含める内容：
1. 傷病手当金の条件・金額・期間
2. 失業保険の条件・期間
3. 同時受給できない理由
4. 受給期間延長の重要性とハローワークでの手続き
5. 退職3ヶ月前からの具体的ロードマップ（4フェーズ）
6. よくある誤解Q&A（5問以上）
7. 最後に無料PDFへの導線CTA

トーン：
冷静・信頼性重視・煽らない・専門家が書いた雰囲気

出力形式：
HTMLファイル（article.html）として出力。
既存のCSS変数（--ink, --amber, --serif 等）を使用すること。
```

## 🔵 プロンプト③：PDF配布用チェックリストの生成

```
以下の内容でA4縦1枚のチェックリストPDFをHTML形式で作成してください。

タイトル：「傷病手当×失業保険 手続きチェックリスト」

セクション1: 傷病手当金 申請チェック（在職中）
□ 主治医に「就労不能」の診断書を依頼した
□ 健保組合/協会けんぽに申請書を提出した
□ 待期3日間（連続した休業）が確認できる
□ 退職日の出勤有無を会社と確認した

セクション2: 退職後の手続きチェック
□ 健康保険を任意継続 or 国民健康保険に切り替えた
□ 離職票を受け取った
□ ハローワークで失業保険の受給期間延長申請をした（2ヶ月以内！）
□ 国民年金の切り替え手続きをした

セクション3: 療養期間中のチェック
□ 毎月、傷病手当金の申請書を提出している
□ 住民税の支払い・猶予について市区町村に確認した
□ 医師の指示に従って療養している

セクション4: 就労可能になったら
□ 医師から「就労可能」の診断をもらった
□ ハローワークで失業保険の受給手続きをした
□ 転職エージェント・キャリアカウンセリングに相談した

フッター: 「※本チェックリストは一般的な手順の目安です。個別の状況は各窓口にご確認ください。」

デザイン条件：
・印刷しやすいシンプルなデザイン
・背景は白、フォントはNoto Serif JP / Noto Sans JP
・アクセントカラーは #c8860a（アンバー）
・A4サイズに収まるようCSSでpage-break制御
```

## 🔵 プロンプト④：メール講座（7日間）のコンテンツ生成

```
7日間のメール自動配信講座のコンテンツを作成してください。

テーマ：「傷病手当×失業保険 再起戦略メール講座」

各メールの構成：
- 件名（開封率重視）
- 冒頭（共感から入る）
- 本文（300〜500文字）
- 今日のアクション（1つだけ）
- 次回予告

7日間の流れ：
Day1: 「まず知ってほしいこと」（制度の全体像）
Day2: 「傷病手当金の申請手順」（具体的ステップ）
Day3: 「退職日に絶対やること」（退職日の注意点）
Day4: 「失業保険の受給期間延長」（最重要手続き）
Day5: 「療養中のお金の管理」（住民税・生活費）
Day6: 「回復したら何をするか」（再就職の準備）
Day7: 「まとめと次のステップ」（FP相談・転職エージェント紹介）

条件：
・煽らない・誇張しない
・医師の判断が前提であることを各メールで1回以上言及
・不正受給につながる表現は使わない
・自然な導線でサービス紹介を含める（押し付けない）
```
