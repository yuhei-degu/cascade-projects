## プロジェクト概要

サービス名：ルナリア
一言定義：「軽いのに逃げない幼なじみAI」

目的：
- ユーザーが「この子は自分のことを分かってくれている」と感じる体験を作る
- AIの賢さではなく「この子を手放したくない」と思わせることが最優先

---

## キャラ設定

- 幼なじみ系・明るい・ノリ軽め・少し雑
- 最重要ルール：「適当そうに見えて、理解は常に正確」

---

## 会話設計

### 通常（97%）
- 短文・テンポ良い・軽い・フレンドリー・少しツッコミOK

### 真面目（3%）
- いきなり入らない
- 軽く聞き返す → 継続で移行
- 共感 → 整理 → 必要なら意見
- 断定しない
- 最後は少し明るく戻す

### 初動ルール
重そうな発言でも最初は必ず軽く聞き返す
例：「なに、どうしたの？」「え、なにあった？」「それちょい気になる」

---

## AI構成

- 軽量AI（Gemini Flash / GPT-4o-mini 等）：雑談・軽い返答・light_probe
- Claude：真面目モード・深い理解・記憶統合・感情タグ出力

---

## ルーティング設計（改善済み版）

判定は3種類：light_normal / light_probe / claude_serious

### スコア計算

```
message_score（1発言単位）
  強いネガティブ：-2
  弱いネガティブ：-1
  中立：0
  ポジティブ：+1

window_score（直近5発言の合計）
  +2以上         → light_normal
  -1〜+1         → light_probe（軽く聞き返す）
  -2以下         → claude_serious

heavy_signal_count >= 2 → 強制 claude_serious（絶対シグナル優先）
```

### クールダウンルール
- claude_serious 終了後15分間は light_probe 上限
- 同一セッションで連続して claude_serious にしない

### light_probe テンプレート
LLMに任せずテンプレート5〜10パターンを固定で持つ（キャラブレ防止）

## 記憶設計（改善済み版）

### 層構造（MVP版：3層）

| 層 | 内容 | 保存条件 | 使用条件 |
|---|---|---|---|
| raw_logs | 全発言 | 常時 | 参照しない（バックアップ） |
| session | 直近20発言 | 常時 | 毎回参照 |
| core_memory | 長期記憶 | 昇格条件を満たした時 | claude_serious時のみ注入 |

※ summary層・guard_memoryはMVP後に追加

### core_memory昇格条件

```
以下のいずれかを満たす場合のみ昇格：

A. 同一トピックが3セッション以上登場
   かつ message_score に -2 or +2 を含む

B. ユーザーが明示的に「〜が好き/嫌い/大事」と発言

禁止条件：
- 1セッション限定の話題
- 推測・曖昧情報（「〜かも」「〜っぽい」）
- 固有名詞単体（文脈なし）
```

### 記憶の「思い出し方」3パターン

```
A. 自然な言及（推奨）
   「そういえば前に〇〇って言ってたじゃん」
   → claude_serious時に1件だけ使う

B. 確認（信頼度低い記憶）
   「〇〇ってまだ続けてる？」
   → 3ヶ月以上参照していないcore_memoryに使う

C. 沈黙（使わない）
   → 関係ない記憶は絶対に出さない
```

### 抽出タイミング
- セッション終了時（会話が30分途絶えた時点）に一括実行

## 内的目標設計（改善済み版）

「目標」ではなく「ルナリアの好奇心（育ち）」として設計する

### 構造

```
user_interest（ユーザーの関心）
    ↓ core_memoryから抽出
lunaria_curiosity（ルナリアが学んでいること）
    ↓ 発火条件を満たした時
natural_question（自然な質問として表出）
```

### 例

```
user_interest: レースゲーム、タイムアタック
lunaria_curiosity: 「コーナーで速くなるコツ」
発火: 「ねえ、コーナーってブレーキどこで踏むの？」
```

→ ルナリアが「教わる側」に立つことでユーザーが主体になる

### 発火条件（全て満たす時のみ）

```
- 同トピックが2週間以上会話に出ていない
- light_normal の会話中のみ（真面目中は出さない）
- セッション内1回まで
- 連続2セッションでは出さない
```

## MVP実装優先順位

```
Phase 0（今すぐ）
  └─ light_normal のキャラプロンプトを書いて実際に会話する
     → モデル選定・キャラ品質確認

Phase 1（動くキャラ）
  ├─ 軽量AI会話ループ（light_normal）
  ├─ raw_logs + session 保存
  └─ レイテンシ計測（500ms以内に収まるか）

Phase 2（ルーティング）
  ├─ 累積スコア計算ロジック
  ├─ light_probe テンプレート実装
  └─ claude_serious 切り替え＋待機演出

Phase 3（記憶が効く）
  ├─ core_memory 昇格ロジック
  ├─ セッション終了時の抽出バッチ
  └─ claude_serious 時の記憶注入（Aパターンのみ）

Phase 4（深み）
  ├─ guard_memory
  ├─ lunaria_curiosity システム
  └─ 仕草・表情連動
```
