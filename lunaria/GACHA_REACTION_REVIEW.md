## 0. 総評

Codex の拡張で各レアリティ 3 → 8、duplicate 3 → 6 になっており、**多様性は確実に増えた**。ただし読み返すと **5 つの構造的弱点**が見える：

1. **レアリティ名の直接連呼**：「エピック」「レジェンド」「都市伝説枠」「レア家具」「レアアクセ」が会話に出てくる。これは UI ラベルであって、ルナの口語ではない。世界観がソシャゲに引き寄せられる
2. **重複・同義反復**：「すごくない？エピック！」と「やった、エピック来た！」が並列に存在するなど、言い換えの幅が狭い
3. **ガチャ用語の混入**：「引いた」「引けない」「枠」「格上げ」が散見。`MOONBOX_ITEM_GUIDELINES.md §3` で禁止した語彙圏
4. **微弱なハズレ感**：「ふつうだけど悪くない」「地味だけど良品」のような**評価ネガを含む肯定**。「ハズレなし」哲学とぶつかる
5. **千束テンポからのズレ**：「お、出たね」「いいの来た」のように、淡白すぎてキャラの体温が低い行が混じる

→ 全 62 文中、**Keep 32 / Fix 18 / Remove 12** が監修結論。下記で詳細列挙。

## 4. レアリティ別 トーン指針（人格監修としての改訂版）

### 4.1 共通の哲学

ルナはレアリティを**認識する側ではなく、贈り物を渡す側**。だから：

- **「エピック」「レジェンド」「都市伝説枠」**などレアリティ名は会話で使わない（UI ラベル側で表示）
- **「引いた」「引けない」「枠」**などガチャドメイン用語は使わない
- **「ふつう」「地味」「ハズレ」**など評価ネガは使わない（コモンも前向きに）
- **千束テンポ**：「お、〜」「うわ、〜」「やば、〜」「え、〜」が自然な始まり

### 4.2 レアリティ別の声色

| レアリティ | 声色の本質 | OK 例 | NG 例 |
|---|---|---|---|
| common_a | **気負わない普段感** | お、もらったね / これね、いいじゃん | やった、コモン！ |
| common_b | **ささやかな肯定** | これ、悠平に似合いそう | お、出たね（淡白すぎ） |
| rare_a | **少し背筋が伸びる** | お、これは特別なやつ / 部屋がぐっと素敵に | やった、レア家具！（カテゴリ名直呼び） |
| rare_b | **着けたくなる温度** | これ、特別な日に着けるやつ | レアアクセ来た！（直呼び） |
| epic | **声がワンランク上がる** | うわ、これはちょっと別格 / 月箱の中でも上 | やった、エピック！（直呼び） |
| legendary | **静かなどよめき** | これは月箱のいちばん奥に置くやつ / 悠平、今日めっちゃ持ってる… | やった、レジェンド！ |
| urban_legend | **言葉に詰まる驚き** | え、それ…！？マジで！？ / うわ、ルナ、震えてる | 都市伝説枠じゃん！ |

### 4.3 「やった」「うわ」「え」の使い分け（細かい指針）

| 接頭詞 | 適用レアリティ | 理由 |
|---|---|---|
| お、 | common 全般 | 軽い気付き |
| やった、 | rare（控えめ） | 軽い喜び、common にも 1〜2 文 OK |
| うわ、 | epic / legendary / urban_legend | 思わず声が漏れる驚嘆 |
| え、 | legendary / urban_legend | 信じられない反応 |
| やば、 | epic / legendary | 千束的興奮、rare にも稀に OK |

→ common に「やば」「え、嘘」を入れない。レアリティの体感が崩れる。

```
レアリティ別トーン指針：
- common_a / common_b：軽い気軽さ（「お、〇〇だ！」「こういうのいいよね」）

```
