## 推奨結論

Codex 推奨は以下。

1. 刺繍ハンカチの「L」は採用
2. urban_legend「ふたりの傘」は採用。ただし説明を少し弱める
3. epic「月夜の鏡」は epic のまま採用
4. リアクション追加は legendary / urban_legend のみ先行

理由：v2 は「世界観を濃くする」フェーズだが、関係性・魔法性を一気に強めすぎると Lunaria の静かな距離感が崩れる。強いものは採用しつつ、説明文で一段だけ抑えるのが安全。

---

## 1. 刺繍ハンカチの「L」

対象：
- `刺繍ハンカチ`
- 新説明案：`すみっこに小さく「L」の刺繍`

推奨：採用

理由：
- 「ルナが渡したかもしれない」くらいの薄い示唆で、押しつけがない
- common_b の日用品に小さな物語が入り、月箱らしい余白が増える
- 直接「ルナの刺繍」と言っていないので重くない

代替案：
- `すみっこに小さな月の刺繍`
- `角が少しだけほつれかけている`

---

## 2. urban_legend「ふたりの傘」

対象：
- `ふたりの傘`
- 原案：`一人で差すと内側に小さな雨音がする`

推奨：採用。ただし名前か説明のどちらかを少し弱める。

理由：
- 「誰かのリング」と同系統の関係性ヒントだが、傘はより日常側なので重くなりすぎにくい
- urban_legend に生活感のある不思議が増える
- 「ふたり」という語は強いので、説明側は淡くするのが安全

推奨文：
- 名前：`ふたりの傘`
- 説明：`一人で差すと、内側だけ雨音が近くなるらしい`

代替案：
- 名前：`雨音の傘`
- 説明：`晴れた日に差しても、内側だけ小さな雨音がするらしい`

---

## 3. epic「月夜の鏡」

対象：
- `月夜の鏡`
- 想定：月・鏡・反射のモチーフを持つ強めのアイテム

推奨：epic のまま採用

理由：
- urban_legend は既に増えているため、epic 側にも「世界観の濃い当たり」が必要
- 物理法則を明確に壊さず、「飾りたくなる一品」として扱えば epic に収まる
- urban_legend に上げる場合は「映るはずのないものが映る」などの説明が必要になり、強くなりすぎる

epic に置く場合の説明案：
- `月のある夜だけ、縁取りが淡く光る`

urban_legend に上げる場合の説明案：
- `覗くと、少しだけ遅れた自分が映るらしい`

---

## 4. gacha-reaction.ts の追加範囲

選択肢：
- A. legendary / urban_legend のみ +3 ずつ
- B. 全レアリティ +3 ずつ
- C. 追加しない

推奨：A

理由：
- v2 で増える世界観の濃いアイテムに対し、高レア帯だけ反応の語彙を厚くすれば効果が出やすい
- 全レアリティ追加は文言レビュー工数が増え、品質が薄まりやすい
- 低レア帯は v1/v2 で既に十分な fallback 数がある

実装方針：
- migration 013 と同じ PR に入れず、別 PR に分ける
- まず DB コンテンツだけ入れて、実際の表示を見てから反応を増やす

以下が決まれば、Codex は `013_gacha_content_v2.sql` を作れる。
