# 月箱（ガチャ）コンテンツ案

作成：2026-04-28
対象：`010_gacha_seed.sql` 改善案 + `gacha-reaction.ts` 拡張用テンプレ + urban_legend 追加候補

設計思想（既存からの継承）：
- パチンコ的・射幸心煽りを徹底回避
- 「ルナからのささやかな贈り物」感を基調
- レインボー演出 / 「もしかして…」連発 / 派手な期待値演出は禁止
- 千束テンポ：1〜2 文、媚びない、押しつけない、ブレない

## 3. urban_legend 追加候補（10 個）

既存 5 種（誰かのリング / 無音の鈴 / どこかで見たコート / 逆さの砂時計 / 瞬きの猫）に追加する候補。

各案は「物理法則を 1 つだけ崩す」「真偽を断定しない」「主観描写で実在感」の 3 原則で構成。

| # | 名前 | 説明 | 設計意図 |
|---|---|---|---|
| 1 | 月の欠片 | 持っていると夜が少し明るく感じる | 既存「月」テーマに直結する象徴アイテム |
| 2 | 影のない傘 | 雨の中で広げても、地面に影が落ちない | 物理法則の最小違反 |
| 3 | からっぽの封筒 | 重みはあるのに、中身は誰にも開けられない | 開けたくなる謎 |
| 4 | 名のない地図 | 描かれた町の名前だけがすべて空白になっている | 旅情と謎 |
| 5 | 二度目のメガネ | かけると、忘れていた小さなことだけ思い出す | 関係性・記憶テーマ |
| 6 | 古いカメラ | フィルムは入っていないのに、撮るとシャッター音だけ残る | 残響というモチーフ |
| 7 | 満たされないグラス | どれだけ飲んでも中身が減らないという噂 | 「らしい／噂」で曖昧化 |
| 8 | 風になる紙ヒコーキ | 投げると風に溶けて、どこかへ届くらしい | 詩的で前向きな魔法 |
| 9 | 砂浜のラジオ | 一度だけ、知らない誰かの声が流れたことがある | 「一度だけ」で希少感 |
| 10 | 鏡うつしの本 | 鏡越しに開くと、物語が一行ずつ浮かんでくる | 鏡＝月の隠喩 |

### urban_legend 全 15 種（既存 5 + 新規 10）の確率配分案

各 drop_weight = 1 で均等。total 0.1% の中で 15 種が等確率（個別約 0.0067%）。

ただし、**月モチーフ強アイテム（月の欠片など）は drop_weight を 1.5 にして「月箱の代表的なアイテム」にする**選択肢もある。たとえば：

| アイテム | drop_weight | 期待出現率 |
|---|---|---|
| 月の欠片 | 1.5 | 0.010% |
| その他 14 種 | 1.0 | 各 0.0064% |
| 合計 | 15.5 | 0.1% |

これは判断委ねる。

## 4. 採用ガイド・適用上の注意

### 4.1 名前・説明文の差し替え

- 既存 `010_gacha_seed.sql` は **`on conflict (name) do nothing`** で運用されているため、名前を変えると**新規 row として追加され、旧名は残る**。
- 旧 row を削除するか、`update` で名前を書き換える migration（例：`012_gacha_rename.sql`）を別途作る必要がある。
- migration 番号は触るなとの指示なので、**この差し替えは別 migration 案として別途相談**。

### 4.2 リアクションテンプレの統合先

- `lib/lunaria/gacha-reaction.ts` の `FALLBACK_NEW` / `FALLBACK_DUPLICATE` を拡張する形が自然。
- 各レアリティ 3 種 → 10 種にすることで、LLM 失敗時のリアクションがパターン化しにくくなる。
- LLM 生成プロンプト内の few-shot にも一部移植可能。

### 4.3 urban_legend 追加の影響

- 5 種 → 15 種で「複数の極レア」化により、ユーザー間で異なる体験が生まれる（既存設計の「都市伝説枠」哲学と整合）。
- 個別出現率が下がるので、「持ってない都市伝説アイテム」が常に存在する状態になる ⇒ 話題作りとしての持続性が向上。

### 4.4 パチンコ的表現の排除確認

本案で意識的に避けたもの：
- 「もしかして…？」の連発
- 「確定」「鉄板」「激熱」のような遊技機用語
- 「神引き」「ガチャ運」のような射幸心ワード
- 「金虹」「赤」のような期待値段階表現
- 「お疲れ様」「頑張った甲斐」のような労いの押し売り

代わりに採用した語彙：
- 「ささやか」「ちょうどいい」「ほっとする」（控えめな肯定）
- 「悠平に合いそう」「使えるやつ」（実用感）
- 「らしい」「気がする」（urban_legend の曖昧化）
- 「いい日だね」「記念日にしよう」（特別感をルナの主観として表現）

## 5. 残された選択肢（要判断）

| 項目 | 選択肢 |
|---|---|
| 既存名の差し替え方式 | A. 別 migration で update / B. 旧 row 削除 + 新規 insert / C. 名前は維持して説明文だけ刷新 |
| urban_legend 個別重み | A. 全 15 種均等 / B. 月の欠片だけ 1.5 倍重み / C. レアリティ内サブティア（"超" urban_legend） |
| リアクションテンプレ採用範囲 | A. 全 80 種を `gacha-reaction.ts` に投入 / B. 各レアリティ 5 種に絞る / C. LLM プロンプトの few-shot のみに使う |
| 千束のコート の名称 | A. 「どこかで見たコート」に改名（公式名を避ける） / B. 「千束のコート」を維持 / C. 「赤いコート」に簡素化 |

これらの判断を経て、最終的に migration / `gacha-reaction.ts` の更新に入るのが安全な順序。
