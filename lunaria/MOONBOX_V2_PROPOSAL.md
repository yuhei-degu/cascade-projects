## 2. urban_legend の次回追加候補（5 個）

### 2.1 採用候補

`MOONBOX_CONTENT_PROPOSAL.md` の未採用 5 個から 3 個 + 新規 2 個の混合構成。これにより v1 の続き感とフレッシュさを両立。

| # | 名前 | 説明 | 出典 / 設計意図 |
|---|---|---|---|
| 1 | 名のない地図 | 描かれた町の名前だけがすべて空白になっている | PROPOSAL 既出。旅情と謎、urban_legend テーマの王道 |
| 2 | 古いカメラ | フィルムは入っていないのに、撮るとシャッター音だけ残る | PROPOSAL 既出。「残響」というモチーフが Lunaria の記憶テーマと響く |
| 3 | 鏡うつしの本 | 鏡越しに開くと、物語が一行ずつ浮かんでくる | PROPOSAL 既出。**鏡 = 月の隠喩**として月箱コンセプトと整合 |
| 4 | 月光のティーポット | お湯を注ぐと、立ち上る湯気が三日月の形になるという | **新規**。月モチーフ追加・生活風景に浸透・「らしい」で曖昧化 |
| 5 | ふたりの傘 | 一人で差すと内側に小さな雨音がする | **新規**。関係性のヒントを urban_legend に持ち込む（誰かのリング と対になる） |

### 2.2 保留（v3 以降）

| 名前 | 説明 | 保留理由 |
|---|---|---|
| 満たされないグラス | どれだけ飲んでも中身が減らないという噂 | 「魔法の道具」感が強すぎ、Lunaria のしっとり感とずれる懸念 |
| 風になる紙ヒコーキ | 投げると風に溶けて、どこかへ届くらしい | 詩的だが「届く」のメタファーが「指輪」「ふたりの傘」と被る |

### 2.3 確率配分

合計 0.1% を **15 種で均等**（各 drop_weight = 1）。個別出現率は約 0.0067%。

「持ってない都市伝説アイテム」が常に存在する状態が維持され、コミュニティでの話題作りが持続する。

「月の欠片を 1.5 倍重み」案は v3 以降に再考。

## 3. レアリティ別 厚み調整（アイテム数の増量）

### 3.1 現状の問題分析

| レアリティ | 現アイテム数 | 確率 | 1 アイテム当たり | 観察される課題 |
|---|---|---|---|---|
| common_a | 5 | 45% | 9.0% | **かぶり頻度が高すぎる** → 新規ユーザーが「またこれか」感を抱きやすい |
| common_b | 5 | 30% | 6.0% | やや高いが許容範囲 |
| rare_a | 3 | 14% | 4.7% | 妥当 |
| rare_b | 3 | 7% | 2.3% | 妥当 |
| epic | 2 | 3% | 1.5% | アイテム選択肢が薄め |
| legendary | 2 | 0.9% | 0.45% | 妥当（高レア感を保つには現状で OK） |
| urban_legend | 10 | 0.1% | 0.01% | 妥当 |

### 3.2 v2 増量の優先度

**最優先：common_a +3（5 → 8）**

かぶり頻度の解消が最大効果。1 アイテム当たり 9.0% → 5.6% に下がり、「初めて引いた」体験が増える。コイン経済を主役化させすぎず、コレクション欲求もそれなりに維持できる。

**次優先：urban_legend +5（10 → 15）**

§2 の追加 5 種を投入。話題性の再生産。

**第三優先：common_b +2（5 → 7）**

common_a に次いで露出が多い帯。多様性を上げる価値あり。

**第四優先：epic +1（2 → 3）**

選択肢が 2 個だけだと記憶の濃度が薄い。+1 で「お、また別のエピックが出た」という喜びを設計可能。

**増やさない：rare_a / rare_b / legendary**

- rare_a/b は現状で十分機能している
- legendary は 2 種だからこそ希少感が成立。増やすと「最高レア」の重みが希釈される

### 3.3 増量の具体案（新規 11 アイテム）

#### common_a 追加 3 種

| 名前 | 説明 |
|---|---|
| 木の小箱 | 中身は空っぽなのに、持っているだけで落ち着く |
| 朝の湯のみ | 縁が少し欠けている、温かい飲み物が似合う |
| 古いマッチ箱 | 振ると、中で乾いた音がする |

#### common_b 追加 2 種

|---|---|

#### epic 追加 1 種

| 名前 | 説明 |
|---|---|
| 月夜の鏡 | 鏡面には部屋が映るのに、なぜか月だけが浮かぶ |

→ **v2 アイテム合計**：30（現状）+ 11（新規）= **41 アイテム**

## 4. 月箱の世界観を崩しそうな表現の NG 集

migration / `gacha-reaction.ts` / 説明文 / リアクションテンプレ / few-shot のすべてに適用される予防的ガイドライン。Codex に共有することで品質維持。

### 4.1 遊技機・パチスロ用語（絶対禁止）

| NG | 理由 / 言い換え |
|---|---|
| 確定 / 鉄板 / 激熱 | パチンコ用語。世界観を一発で崩す |
| 大当たり / アツい | 同上 |
| 7 揃い / 高設定 / リーチ | 同上 |
| 当選 / 抽選確定 | 「贈り物」感が消える |

### 4.2 射幸心煽り語（禁止）

| NG | 言い換え候補 |
|---|---|
| 神引き / 爆死 / 天井 / 単発 | 「運いいね」「ラッキー」など中性的に |
| 〇連目で！ / 何連目で！ | 数字で煽らない。「今日いい日だね」など |
| 爆アツ | 「うわ、これは…」など余韻で表現 |

### 4.3 期待値段階表現（禁止）

| NG | 理由 |
|---|---|
| 金虹 / 赤虹 / 銀枠 | パチスロ的色覚誘導。Lunaria の演出が「贈り物」型なので不要 |
| 信頼度 X% | パチンコ用語。LLM が偶然出してきても削除する |
| 〇〇確定アイコン | 同上 |

### 4.4 押しつけがましい労い（禁止）

| NG | 言い換え |
|---|---|
| お疲れ様 | （v8 プロンプトで既に禁止） |
| 頑張った甲斐 / 待った甲斐 | 「いい日だね」「記念日にしよう」（ルナ主観で表現） |
| 努力が実った | 不要 |

### 4.5 キャラ崩壊・媚び表現（禁止）

| NG | 理由 |
|---|---|
| ご主人様 / ダーリン / 旦那様 | キャラ崩壊（ルナは幼なじみ系・千束テンポ） |
| 〇〇ってばぁ / きゃー / 萌え | お姉さん系・媚び表現（v8 プロンプトでも明示禁止） |

### 4.6 過剰な感情表現（避ける）

| NG | 言い換え |
|---|---|
| 涙が出ちゃう / 鳥肌 / 震えが止まらない | 「ちょっと震えてる」程度の控えめな表現に |
| 一生忘れない / 永遠に大切 | 「記念日にしてもいいやつ」のように主観の遊びとして残す |
| 死ぬほど嬉しい / 倒れた | 過剰、Lunaria の落ち着きを損なう |

### 4.7 金銭・数字直結（禁止）

| NG | 理由 |
|---|---|
| 万円相当 / 〇連分の価値 | 商品価値で語るとガチャの本質が「換金性」にすり替わる |
| 価値が高い / 価値が低い | 「ささやかな贈り物」哲学と矛盾 |

### 4.8 ネガティブ表現（ハズレ感）（禁止）

| NG | 言い換え |
|---|---|
| ハズレ / 残念 / 期待外れ | 「ハズレなし設計」を死守。コモンも「ささやか」で前向きに |
| こんなのいらない / しょぼい / がっかり | コモン排出時のリアクションで絶対出さない |

### 4.9 競争・FOMO 煽り（禁止）

| NG | 理由 |
|---|---|
| 〇〇さんは引いた / 友達はもう持ってる | 比較で焦らせるのは依存装置 |
| 急がないと無くなる / 期間限定（短期煽り） | パチンコ的限定モチーフ。長期コレクション哲学と矛盾 |
| 〇〇までに引かないと | カウントダウン演出は依存装置 |

### 4.10 適切な表現（チートシート）

採用すべき語彙（v1 で実績あり）：

- 「ささやか」「ちょうどいい」「ほっとする」（控えめな肯定）
- 「悠平に合いそう」「使えるやつ」（実用感）
- 「らしい」「気がする」「〜って聞いた」（urban_legend の曖昧化）
- 「いい日だね」「記念日にしよう」（特別感をルナの主観で表現）
- 「これ、ちゃんと飾ろう」「大事にしよう」（受け取りの儀式感）

## 7. v3 以降に持ち越す候補（記録）

本提案で意図的に見送ったもの：

- C 区分の 4 アイテム（花瓶 / 貝殻のブローチ / 虹色イヤリング / 北欧チェア）→ 効果が subtle、優先度低

- ピックアップ機能（特定 urban_legend が一定期間出やすくなる）→ 別 phase 案件
- 天井機能（500 連で urban_legend 確定）→ 既存 PHASE_G_GACHA_DESIGN.md の 2.6 で言及済み、別 phase

## 8. 議論したい論点（実装前の確認事項）

Codex 引き渡し前にユーザーと合意したい項目：

1. **「L」の刺繍（刺繍ハンカチ）はキャラ世界観に合うか？**
   - YES なら採用、NO なら別の説明に差し替え（例：「角がほつれかけている」）

2. **新規 urban_legend のうち「ふたりの傘」は関係性の踏み込みが強くないか？**
   - 「誰かのリング」と被る関係性ヒントを 2 個入れるのが過剰なら削除候補

3. **epic +1 の「月夜の鏡」は urban_legend に上げた方が世界観整合的か？**
   - 物理法則を 1 つ崩している点は urban_legend 寄り。ただ epic 帯にも世界観強アイテムが欲しい

4. **`gacha-reaction.ts` の追加範囲（legendary/urban_legend のみ vs 全レアリティ）**
   - 限定する方針で良いか、もしくは全レアリティに +3 ずつにするか

これらの判断後、Codex に渡せる最終 v2 仕様になる。
