## 1. レアリティ 7 段階の違い

各レアリティを「**何が中心か / 詩的密度 / 物理法則 / 月モチーフ強度**」の 4 軸で整理。

| レアリティ | 確率 | 中心カテゴリ | 詩的密度 | 物理法則 | 月モチーフ強度 |
|---|---|---|---|---|---|
| common_a | 45% | 家具・小物 | 低（実用感） | 通常 | 弱（散らす程度） |
| common_b | 30% | アクセサリー（日用） | 低（シンプル） | 通常 | 弱 |
| rare_a | 14% | 家具（印象的） | 中（時間帯・場面の具体描写） | 通常 | 中（許容） |
| rare_b | 7% | アクセサリー（特別感） | 中（光・音・色などの現象） | 通常 | 中 |
| epic | 3% | カテゴリ自由（飾りたくなる） | 中〜高 | 通常 | 中〜強 |
| legendary | 0.9% | カテゴリ自由（実在の特別品） | 高（現象が主役） | 通常 | 強（OK） |
| urban_legend | 0.1% | 「都市伝説」カテゴリ専用 | 高（散文詩） | **1 つだけ崩す** | 強推奨 |

### 1.1 軸の解説

- **詩的密度**：説明文がどれだけ「文学的」か。低 = 「居心地いい」、中 = 「窓辺に置くと光がよく入る」、高 = 「中に小さな星が閉じ込められているような」
- **物理法則**：違反するか否か。違反 OK は urban_legend のみ。他レアリティで違反すると線引きが崩れる
- **月モチーフ強度**：名前 / 説明にどれだけ月（三日月・満月・月光・月相など）が出るか
- **重要**：legendary と urban_legend の違いは「**実在 vs 噂**」。legendary は「すごい現象が起きる**実在**の品」、urban_legend は「**あるかわからない**噂のもの」

### 1.2 線引きの典型例

| 例 | 妥当なレアリティ | 理由 |
|---|---|---|
| やわらかいクッション | common_a | 日常品・実用感 |
| 月見クッション | common_a | 月モチーフ薄く、common_a の許容範囲 |
| 月光のチョーカー | rare_b | アクセ + 月モチーフ + 現象描写 |
| 満月のランプ | legendary | 月モチーフ強・現象が主役・実在 |
| 月の欠片 | urban_legend | 月モチーフ強・「らしい」で曖昧化・物理法則違反（夜が明るく感じる） |

## 2. 各レアリティにふさわしいアイテム例

### 2.1 common_a（45%）— ささやかな家具・小物

「ルナが拾って渡してくれた、ちょっとしたもの」感。

**OK**：クッション、椅子、花瓶、本、ろうそく、湯のみ、マッチ箱、小箱、メモ帳、コースター
**NG**：宝石、王冠、刀、宝箱、神器、フラスコ（魔術師感）、トロフィー

### 2.2 common_b（30%）— ふつうのアクセサリー

「身につけられる小さなもの」。シンプル・日常感。

**OK**：ブローチ、しおり、ハンカチ、リボン、ペンダント、ブレスレット、髪留め、シンプルなリング
**NG**：高級時計、ダイヤモンド、ティアラ、エンブレム、ブランド品、勲章

### 2.3 rare_a（14%）— レア家具

「印象に残る・部屋の格上げになる」家具。

**OK**：アンティーク時計、ステンドグラス、北欧チェア、レコード機、和風行灯、月相時計、古い鏡
**NG**：ファッション系雑貨、現代家電、宇宙船パーツ、武器、玉座

### 2.4 rare_b（7%）— レアアクセサリー

「ちょっと特別・着けたくなる」アクセ。光・色・現象などの繊細な描写を伴う。

**OK**：月光のチョーカー、プリズムイヤリング、古代風コイン、銀細工、彫り入りのリング
**NG**：流行ブランド、過度に派手な宝飾、現代スマートウォッチ

### 2.5 epic（3%）— 上位レア

カテゴリ自由。「飾りたくなる・印象的」レベル。

**OK**：真珠、楽器（古いオルゴール）、月夜の鏡、深海の品、稀少な書籍、彫像
**NG**：国宝級、神器、伝説の武器、最強装備、ファンタジー RPG 系

### 2.6 legendary（0.9%）— 最高レア

「滅多に見ない、実在の特別な品」。月モチーフ濃厚 OK。生活描写から少し離れて、**現象が主役**になる。

**OK**：満月のランプ、流星の万年筆、夜空の壺、月の砂時計、星屑のインク
**NG**：神器、王冠、剣、最強装備、創世の○○、神話の○○、勇者の○○

→ legendary でも「物理法則違反」はしない。あくまで**美しい現象が起きる実在の物**。

### 2.7 urban_legend（0.1%）— 都市伝説枠

物理法則を**1 つだけ**崩す品。「らしい」「気がする」「と聞いた」で**必ず曖昧化**。

**OK**：影のない傘、無音の鈴、瞬きの猫、月の欠片、二度目のメガネ、からっぽの封筒、砂浜のラジオ、鏡うつしの本
**NG**：呪いの○○、神の○○、魔法の○○、勇者の○○、スター・ウォーズ的、中世ファンタジー語彙

## 3. 各レアリティに入れてはいけない表現

レアリティ間の差を保つために、特定のレアリティでは使うべきでない表現がある。

### 3.1 common_a / common_b の禁止表現

| NG 表現 | 理由 |
|---|---|
| 特別 / レア / 貴重 | レアリティ感を common で主張すると線引きが崩れる |
| 滅多に / 神級 / 最高 | 同上 |
| 物理法則違反 | urban_legend と被る |
| 「らしい」「気がする」 | urban_legend の語彙を common で使うと線引きが崩れる |
| 派手な月モチーフを名前の中心に | rare 以上の領分 |

例：「奇跡のクッション」「神聖なリング」は common 不可。

### 3.2 rare_a / rare_b の禁止表現

| NG 表現 | 理由 |
|---|---|
| ハズレ感 / ふつう / そこそこ | レア感を毀損 |
| 「ありがちな」「どこにでもある」 | レアの線引き崩壊 |
| 物理法則違反 | urban_legend と被る |

### 3.3 epic の禁止表現

| NG 表現 | 理由 |
|---|---|
| 最高 / 最強 / 神級 / 究極 | legendary との差が曖昧になる |
| 物理法則違反 | urban_legend と被る |
| 「らしい」「気がする」 | 同上 |

### 3.4 legendary の禁止表現

| NG 表現 | 理由 |
|---|---|
| 「らしい」「気がする」「という」 | これらは **urban_legend の専用語彙**。legendary は「実在の特別品」 |
| 物理法則違反 | 同上、urban_legend との線引き |
| 神話・神器系の語彙（神剣、聖杯など） | Lunaria の世界観（ささやかな贈り物）と矛盾 |

→ legendary と urban_legend の最大の違いは**「実在性」**。legendary は「すごい現象が起きるが、実在する」、urban_legend は「あるかわからない、噂レベル」。

### 3.5 urban_legend の禁止表現

| NG 表現 | 理由 |
|---|---|
| 「確実に」「絶対に」「100%」 | 断定すると都市伝説感が消える |
| 固有名詞 / 既存 IP（後述） | 法的リスク |
| 物理法則を 2 つ以上崩す | ファンタジー化、SF 化 |
| 神 / 魔 / 呪い / 死 | 中世ファンタジーの語彙、世界観ずれ |
| ホラー寄り（血、闇、骸骨など） | Lunaria の落ち着きが崩壊 |
| 過剰な美化（魔法のような、奇跡の） | 「ささやかな」哲学と矛盾 |

## 4. urban_legend を増やすときの注意点

このレアリティは特に繊細。**運用ミスが世界観を一発で壊す**ので、追加時は他レアリティ以上に慎重に審査する。

### 4.1 必須要件チェックリスト

新規 urban_legend 候補を提案する際、すべて満たしているか確認：

- [ ] 物理法則違反は**1 つだけ**（複数違反すると魔法 / SF に寄る）
- [ ] 説明文に **「らしい」「気がする」「という」「〜したことがある」** のいずれかが含まれている
- [ ] 名前は **5〜10 文字程度**、漢字+ひらがなの混合
- [ ] 説明文は **20〜40 文字程度**
- [ ] 既存 urban_legend のギミックと被っていない（同種の物理違反がない）
- [ ] ホラー / 怖さの要素がない（鏡 OK、呪い NG）
- [ ] 月モチーフ・関係性モチーフ・記憶モチーフのいずれかと接続している（孤立アイテムにしない）
- [ ] 固有名詞ゼロ（§5 のチェックリスト参照）

### 4.2 ギミック被りチェック

既存 10 種の urban_legend のギミック分類：

| 既存アイテム | ギミック種別 |
|---|---|
| 誰かのリング | 関係性・温かさ |
| 無音の鈴 | 音の逆転 |
| どこかで見たコート | 既視感 |
| 逆さの砂時計 | 重力反転 |
| 瞬きの猫 | 主観的な発見 |
| 月の欠片 | 環境変化 |
| 影のない傘 | 影の喪失 |
| からっぽの封筒 | 中身の謎 |
| 二度目のメガネ | 記憶喚起 |
| 砂浜のラジオ | 一度きりの現象 |

新規候補は**これらと違うギミック**を持つこと。例：「重力反転」は既に砂時計があるので、新規で重力系を出すなら別の角度（浮く / 落ちない / 逆さに立つ）にする。

### 4.3 出現率増加時の影響

10 種 → 15 種：個別出現率 0.01% → 0.0067%。話題性は持続するが、**プレイヤーが特定アイテムを見る確率が下がる**。

- 15 種以上にする場合、urban_legend 全体の確率を 0.1% → 0.15% に上げる議論が必要（ただし上げすぎると希少感が失われる）
- 推奨ライン：**最大 20 種で頭打ち**。それ以上はピックアップ機能や月替わりローテーションの実装を検討

## 5. 既存 IP・固有名詞を避けるためのチェックリスト

法的リスク回避のための事前審査。

### 5.1 NG カテゴリ

以下を含むアイテム名・説明は**必ず差し替え**：

| カテゴリ | 例 |
|---|---|
| アニメ・漫画作品名 / キャラ名 | リコリス、ピカチュウ、ミッキー、ナルト |
| ブランド名 | ティファニー、シャネル、エルメス |
| 実在の人名 | 著名人・作家・歴史的人物の固有名 |
| 楽曲・小説・映画タイトル | 「君の名は。」「千と千尋」 |
| 商標登録された名称 | ウォークマン、ジップロック、セロテープ |
| 特定企業の固有商品名 | iPhone、Switch、Kindle |
| 神話・宗教の固有名 | エクスカリバー、聖杯、ロンギヌス |

### 5.2 グレーゾーンと処理

| 表現 | 処理 |
|---|---|
| 「赤いコート」 | OK（一般名詞の組み合わせ） |
| 「千束のコート」 | NG（リコリス・千束を直接参照） |
| 「どこかで見たコート」 | OK（v1 で採用済み、間接化） |
| 「魔女の宅配便」 | NG（ジブリ作品） |
| 「黒猫の小包」 | OK（一般描写） |
| 「ムーミンのマグカップ」 | NG（キャラ名） |
| 「白いカバ」 | NG だがマグカップは OK（一般化）|

### 5.3 事前審査の手順

新規アイテム名を確定する前に：

1. **検索エンジンで叩く**：アイテム名で Google 検索。特定 IP のヒットが多ければ NG
2. **直訳・カナ転換**：英訳・カナ表記でも検索（「Tsukimi Cushion」など）
3. **間接化を試みる**：「〜のような」「〜風の」「どこかで見た」で言い換えられないか
4. **一般名詞 + 形容**で再構成可能なら必ずそうする

### 5.4 実装後の発見ケース

リリース後に「実は商標だった」と判明した場合の対応：

- 既存インベントリ保有者がいる場合：UPDATE で名前変更（DELETE 禁止）
- 名前変更時はユーザーへ告知（「『○○』を『△△』に改称しました」）
- 説明文も併せて見直し

## 6. 今後アイテムを追加するときのレビュー観点

PR / migration レビュー時のチェックリスト。

### 6.1 レアリティ整合性

- [ ] アイテムのレアリティが、既存の同レアリティ群と**粒度が揃っているか**
- [ ] 説明文の詩的密度がレアリティに対応しているか（§1.1 参照）
- [ ] common に高級感の強いものを入れていないか
- [ ] legendary に日常品を入れていないか
- [ ] urban_legend に物理法則を守るものを入れていないか

### 6.2 世界観整合性

- [ ] 月モチーフ・記憶モチーフ・関係性モチーフのいずれかと接続しているか
- [ ] 「贈り物」感を出せているか（ハズレ感ゼロ）
- [ ] 千束テンポと矛盾しないか（重すぎる / お姉さん風 でないか）
- [ ] ルナの存在を仄めかすアイテムは少数に絞られているか（多用すると重い）

### 6.3 表現審査

- [ ] パチンコ用語を含まないか（確定 / 鉄板 / 激熱 / 大当たり）
- [ ] 射幸心煽り語を含まないか（神引き / 天井 / 単発 / 爆死）
- [ ] 過剰な感情表現を含まないか（永遠に / 一生 / 死ぬほど）
- [ ] ハズレ感を出していないか（残念 / がっかり / コモンかよ）
- [ ] FOMO 表現を含まないか（期間限定 / 急がないと / 今だけ）

### 6.4 IP・固有名詞

- [ ] §5.1 の NG カテゴリに該当しないか
- [ ] 検索エンジンで叩いて特定 IP のヒットがないか
- [ ] グレーゾーン表現は間接化されているか

### 6.5 データ整合性

- [ ] 名前がユニーク（既存と被らない・`unique` 制約に違反しない）
- [ ] 名前が 5〜15 文字程度の自然な長さ
- [ ] 説明文が 20〜40 文字程度
- [ ] image_url がプレースホルダーから本素材に切り替わるタイミングが計画されているか
- [ ] migration が DELETE+INSERT ではなく UPDATE+INSERT で構成されているか
- [ ] `on conflict (name) do nothing` で再実行可能か

### 6.6 urban_legend 固有チェック（追加時のみ）

- [ ] 物理法則違反は 1 つだけか
- [ ] 「らしい」「気がする」「という」のいずれかを含むか
- [ ] ホラー要素がないか
- [ ] 既存 urban_legend のギミックと被らないか（§4.2 参照）
- [ ] 月モチーフ・記憶モチーフ・関係性モチーフのいずれかと接続しているか

## 7. レビュー時のコミュニケーション原則

### 7.1 「却下」は避け、「軸を合わせる」会話に

新規アイテム提案を全否定するのではなく、本ガイドラインの軸でフィードバックする：

- ❌「これは違う」
- ✅「common_a としては詩的密度が高すぎる。rare_a に上げるか、説明を 1 段階シンプルに（例：『○○』）」

### 7.2 PR テンプレート（推奨）

migration / `gacha-reaction.ts` 系の PR では以下を記載：

```markdown
## 変更内容
- 追加：N アイテム（rarity 別内訳）
- 変更：N アイテム（rarity 別内訳）

## レアリティ整合性チェック
- [ ] 既存の同レアリティ群と粒度が揃っている
- [ ] 詩的密度が対応している

## 世界観整合性チェック
- [ ] 月／記憶／関係性のモチーフと接続
- [ ] ハズレ感ゼロ

## 表現審査
- [ ] パチンコ用語なし
- [ ] FOMO 表現なし

## IP チェック
- [ ] 検索済み、特定 IP ヒットなし
- [ ] 一般名詞 + 形容で構成

## urban_legend の場合のみ
- [ ] 物理法則違反 1 つだけ
- [ ] 既存ギミックと被らない
```

このテンプレを GitHub の Pull Request Template として登録すると、レビュー漏れが減る。
