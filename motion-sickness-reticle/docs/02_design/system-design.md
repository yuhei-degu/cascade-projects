**バージョン**: 1.0.0  
**作成日**: 2026-02-22

---

## 1. 技術スタック

| レイヤー | 技術 | 理由 |
|---------|------|------|
| フロントエンド | HTML5 / CSS3 | インストール不要、すぐ動く |
| スタイリング | Vanilla CSS (CSS変数) | 軽量・学習に最適 |
| ロジック | Vanilla JavaScript | ライブラリ不要で学習向け |
| データ保存 | localStorage | ブラウザ内保存、サーバー不要 |
