# 📋 要件定義書 — 酔い止め照準器アプリ

**プロジェクト名**: Motion Sickness Reticle  
**バージョン**: 1.0.0  
**作成日**: 2026-02-22  
**作成者**: yuuve

---

## 1. プロジェクト概要

### 1.1 背景・目的
VR・FPSゲームや動画視聴中に発生する「ゲーム酔い（Motion Sickness）」を軽減するため、
画面中央に固定された照準器（レティクル）を表示するオーバーレイアプリを開発する。

### 1.2 解決する問題
- 画面の揺れと頭の感覚のズレによる酔い
- 画面中央の固定点がないことによる空間認識の乱れ

---

## 2. ユーザー要件

### 2.1 対象ユーザー
- ゲームや動画で酔いを感じる人
- VRコンテンツを楽しみたい人
- プログラミング初心者（アプリ改造・学習用途）

### 2.2 ユーザーストーリー
| ID | ストーリー | 優先度 |
|----|-----------|--------|
| US-01 | ユーザーとして、画面中央に照準器を表示したい | 高 |
| US-02 | ユーザーとして、照準器の種類を選びたい（クロス、ドット、円） | 高 |
| US-03 | ユーザーとして、照準器の色・サイズを変更したい | 中 |
| US-04 | ユーザーとして、透明度を調整したい | 中 |
| US-05 | ユーザーとして、ショートカットキーで表示/非表示を切り替えたい | 低 |

---

## 3. 機能要件

### 3.1 必須機能（Must Have）
- 画面中央への照準器固定表示
- 照準器の形状選択（クロス、ドット、円形、カスタム）
- 色の変更機能（カラーピッカー）
- サイズ調整（スライダー）

### 3.2 あると良い機能（Should Have）
- 透明度（オパシティ）調整
- 位置の微調整（X/Y座標）
- プリセット保存・読み込み
- キーボードショートカット

### 3.3 将来的な機能（Could Have）
- 複数モニター対応
- ゲームプロセス自動検出
- アニメーション付き照準器

---
