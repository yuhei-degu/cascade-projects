# 🎯 酔い止め照準器アプリ (Motion Sickness Reticle)

VR・ゲームプレイ中の酔いを軽減するオーバーレイ照準器アプリ。

## 📁 ディレクトリ構成

```
motion-sickness-reticle/
├── README.md              ← このファイル
├── CHANGELOG.md           ← 変更履歴
├── docs/
│   ├── 01_requirements/   ← 要件定義書
│   ├── 02_design/         ← 設計書
│   ├── 03_implementation/ ← 実装メモ
│   └── 04_testing/        ← テスト仕様
└── src/
    ├── index.html                    ← メインアプリ
    ├── minimal-overlay.html          ← 最小オーバーレイ版
    ├── motion-sickness-reticle.html  ← 照準器メイン
    ├── my-code.html                  ← 開発用テスト
    └── assets/
        ├── css/   ← スタイルシート
        ├── js/    ← JavaScriptファイル
        └── images/ ← 画像素材
```

## 🚀 使い方

1. `src/index.html` をブラウザで開く
2. ゲームや動画の上にウィンドウを重ねる
3. 照準器の種類・サイズ・色を調整する
