# ① 要件定義書 — RequestForge (何でも作成依頼サイト)

**プロジェクト名**: RequestForge  
**バージョン**: 1.0.0  
**コンセプト**: 依頼者がシステム・サイト・プログラムを依頼 → AI自動審査 → Claude Codeで制作 → 承認・決済 → 納品

---

## 1. ユーザーフロー

```
[依頼者]
  ↓ フォームで依頼投稿（タイトル・詳細・予算・メアド）
[システム]
  ↓ DB保存 + Gemini & GPT-4 で同時審査
  ├── 実現不可能 → 自動お断りメール送信 → 終了
  └── 実現可能 → 管理者通知 + Claude Codeでビルド開始
[管理者]
  ↓ 制作完了 → 「確認お願い」メールを依頼者へ送信
[依頼者]
  ↓ プレビューページで確認（「これでOK」or「修正依頼」）
[システム]
  ├── 修正依頼 → 管理者に戻る
  └── 承認 → 決済ページへ
[依頼者]
  ↓ Stripe で決済
[システム]
  ↓ 決済完了 → 納品メール（GitHubリンク or ZIPダウンロード）
```

---

## 2. 機能要件

### 2-1. 依頼投稿フォーム
- タイトル（必須、最大100文字）
- 詳細説明（必須、最大3000文字）
- 希望予算（任意、プルダウン: ¥5K/¥10K/¥30K/¥50K/相談）
- 依頼カテゴリ（Webサイト/Webアプリ/スクリプト/デザイン/相談/その他）
- 連絡先メールアドレス（必須）
- 希望納期（任意）

### 2-2. AI自動審査（Gemini + GPT-4同時評価）
- 実現可能性スコア（0-100）
- 見積もり工数（時間）
- 見積もり価格提案
- 懸念点リスト
- 両モデルが「不可」と判定した場合 → 自動お断りメール
- 審査結果は admin から確認・上書き可能

### 2-3. 管理者ダッシュボード
- 全依頼一覧（ステータス別フィルター）
- 依頼詳細（AI審査結果・会話履歴）
- ステータス更新（受付中/制作中/確認待ち/修正中/決済待ち/完了/却下）
- メール送信（テンプレート選択）
- Claude Code ビルドログ表示エリア

### 2-4. プレビュー・承認ページ（依頼者向け）
- トークン認証（URLに埋め込み、24h有効）
- 成果物プレビュー（iframe or スクリーンショット）
- 「これでOK」「修正が必要」ボタン
- 修正コメント入力欄

### 2-5. 決済（Stripe）
- Stripe Checkout セッション生成
- Webhook で決済確認
- 決済完了後に納品メール自動送信

### 2-6. メール（Resend）
- お断りメール（AI審査不可時）
- 制作開始通知
- プレビュー確認依頼
- 修正承りメール
- 決済依頼メール
- 納品完了メール

---

## 3. ステータス遷移

```
pending（投稿直後）
  → reviewing（AI審査中）
  → rejected（AI審査否決 or 管理者却下）
  → accepted（承認・制作開始）
  → building（Claude Code で制作中）
  → review_ready（依頼者確認待ち）
  → revision（修正中）
  → payment_pending（決済待ち）
  → paid（決済完了）
  → delivered（納品完了）
```

---

## 4. 非機能要件

| 項目 | 要件 |
|------|------|
| 認証 | 管理者は NextAuth (Credentials) |
| セキュリティ | プレビューURLはランダムトークン（UUID）、CORS設定 |
| メール | Resend API（代替: Nodemailer + SMTP） |
| 決済 | Stripe（テストモード対応） |
| DB | PostgreSQL + Prisma |
| デプロイ | Vercel + Railway (DB) / Docker対応 |
| ログ | 全APIリクエスト・AIコールをDBに記録 |
