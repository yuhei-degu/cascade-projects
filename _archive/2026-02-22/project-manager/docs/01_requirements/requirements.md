# 📋 要件定義書 — プロジェクト管理アプリ

**プロジェクト名**: Project Manager  
**作成日**: 2026-02-22

## 目的
複数の開発プロジェクトの進捗・タスクをビジュアルに管理する。

## 機能要件
| ID | 機能 | 優先度 |
|----|------|--------|
| F-01 | プロジェクト作成・削除 | 高 |
| F-02 | タスクのカンバンボード（未着手/進行中/完了） | 高 |
| F-03 | 進捗バーの自動計算・表示 | 高 |
| F-04 | タスクの優先度設定（高/中/低） | 中 |
| F-05 | メモ・コメント機能 | 中 |
| F-06 | ローカルストレージへの永続保存 | 高 |
| F-07 | プロジェクト統計ダッシュボード | 中 |

## 画面構成
- ダッシュボード: 全プロジェクト概要・統計
- プロジェクト詳細: カンバンボード + メモ
- 設定: テーマ変更など

## 技術スタック
- HTML5 / CSS3 / Vanilla JavaScript
- localStorage（データ永続化）
- CSS Grid + Flexbox（レイアウト）
