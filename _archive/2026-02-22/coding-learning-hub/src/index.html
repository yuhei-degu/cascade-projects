HTMLタグの基本

HTMLはWebページの「骨格」。タグで文章に意味を持たせる言語。

HTML
<!DOCTYPE html>
<html lang="ja">
  <head>
    <title>はじめてのHTML</title>
  </head>
  <body>
    <h1>こんにちは！</h1>
    <p>これは段落です。</p>
  </body>
</html>
理解度: 80%
📝

フォーム要素

input、button、select などユーザーが入力できる要素。

HTML
<form>
  <label>名前:</label>
  <input type="text" placeholder="例: yuuve">
  <button type="submit">送信</button>
</form>
理解度: 60%
🎨

Flexboxレイアウト

要素を横並びや縦並びに整列させる、最重要CSSレイアウト技術！

CSS
.container {
  display: flex;
  justify-content: center; /* 横方向の整列 */
  align-items: center;     /* 縦方向の整列 */
  gap: 16px;               /* 要素間のスペース */
}
理解度: 70%
✨

CSS変数とアニメーション

変数で色を管理、transitionやkeyframesで動きをつける！

CSS
:root { --color: #6C63FF; }
.btn {
  background: var(--color);
  transition: transform 0.2s;
}
.btn:hover { transform: scale(1.05); }
理解度: 50%
⚡

DOM操作の基本

JavaScriptでHTMLの要素を取得・変更する最重要スキル！

JavaScript
// 要素を取得
const btn = document.getElementById('myBtn');
// クリックイベントを設定
btn.addEventListener('click', () => {
  document.body.style.background = 'purple';
  console.log('クリックされた！');
});
理解度: 65%
💾

localStorage（データ保存）

ブラウザにデータを保存！設定やメモをページ閉じても覚えておける。

JavaScript
// 保存
localStorage.setItem('name', 'yuuve');
// 読み込み
const name = localStorage.getItem('name');
// 削除
localStorage.removeItem('name');
理解度: 45%
