# 📚 要件定義書 — プログラミング学習ハブ

**プロジェクト名**: Coding Learning Hub  
**対象**: 初心者プログラマー（yuuve）  
**作成日**: 2026-02-22

---

## 1. 目的
自分が実際に作ったアプリをポートフォリオとして見せながら、
HTML/CSS/JavaScriptの学習内容をまとめた「自分専用学習サイト」を構築する。

## 2. 機能要件

| ID | 機能 | 優先度 |
|----|------|--------|
| F-01 | 学習トピック一覧（HTML/CSS/JS） | 高 |
| F-02 | コードサンプル表示（コピーボタン付き） | 高 |
| F-03 | 自作アプリのポートフォリオ展示 | 高 |
| F-04 | 学習進捗チェックリスト | 中 |
| F-05 | おすすめ外部リンク集 | 中 |
| F-06 | ダークモード切替 | 低 |

## 3. 画面構成
- トップページ（ヒーロー + ナビゲーション）
- 学習コンテンツページ（HTML/CSS/JS別タブ）
- ポートフォリオページ（作品一覧）
- リソースページ（外部リンク集）

## 4. 技術スタック
- HTML5 / CSS3（グラデーション・アニメーション）
- Vanilla JavaScript
- localStorage（進捗保存）
- Highlight.js（コードシンタックスハイライト）
