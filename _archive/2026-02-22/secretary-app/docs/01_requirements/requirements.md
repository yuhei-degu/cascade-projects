# 📋 要件定義書 — 秘書アプリ (Secretary App)

**プロジェクト名**: My Secretary  
**作成日**: 2026-02-22

## 目的
日々のスケジュール・タスク・メモ・リマインダーを一元管理する
「自分専用デジタル秘書」アプリ。

## 機能要件
| ID | 機能 | 優先度 |
|----|------|--------|
| F-01 | 今日のダッシュボード（日時・天気風情報・一言） | 高 |
| F-02 | クイックメモ（即座に書ける付箋メモ） | 高 |
| F-03 | TODOリスト（チェックボックス・優先度） | 高 |
| F-04 | スケジュール帳（今日の予定一覧） | 高 |
| F-05 | カウントダウンタイマー | 中 |
| F-06 | 習慣トラッカー（毎日チェック） | 中 |
| F-07 | ローカルストレージ永続保存 | 高 |
| F-08 | 動機づけの一言（ランダム表示） | 低 |

## 画面構成
- メインダッシュボード
  - 左: 時計・今日の予定・習慣
  - 中央: クイックメモ・TODO
  - 右: タイマー・統計
