# 🗄️ Archive

ここは **使わないが消したくないもの** を保管する場所。

## 命名規則
```
_archive/
└── YYYY-MM-DD/   ← アーカイブした日付
    └── プロジェクト名/
```

## ルール
- `_archive/` 内のファイルは直接編集しない
- 復元したい場合は `CascadeProjects/` 直下にコピーして作業
- アンダースコア `_` 始まりでエクスプローラーの一覧の先頭に固まる（意図的）
