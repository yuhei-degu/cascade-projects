## 実施した確認

### ビルド

コマンド:

```bash
npm run build
```

結果:

- 成功
- Next.js の型チェック、静的生成ともに通過
- `/games` と `/games/memory-quest` がビルド対象に追加された

### ゲーム一覧・記憶迷宮スモーク

コマンド:

```bash
LUNARIA_BASE_URL=http://localhost:3013 npm run games:smoke
```

結果:

- `/games`: OK
- `/games/memory-quest`: OK
- 記憶迷宮ルナリアのクリア可能な成長ルート: OK

確認した内容:

- ゲーム一覧に `記憶迷宮ルナリア` と `終末世界` が表示される
- 企画中ゲームとして `夢境修復士ルナリア` と `月庭裁判` が表示される
- 記憶迷宮に `記憶 / 共感 / 洞察 / 勇気` が表示される
- `失敗しても能力が上がる` ルールが表示される
- 能力不足で失敗しても成長し、繰り返しでクリアできるルートがある

## 自己レビュー

### 合格点

- 仕様、実装、テストが一通りつながった。
- 終末世界を壊さず、ゲーム一覧と攻略型ゲームを追加できた。
- 記憶迷宮は「失敗しても成長し、最終的にクリアできる」ことをスモークで確認した。
- 会話スモークも通っており、既存の会話機能を壊していない。

### まだ弱い点

- ブラウザ操作によるクリック自動テストは未実施。
- 記憶迷宮の能力はまだローカル固定値で、実際の記憶DBやガチャ持ち物とは未連携。
- 演出、アニメーション、ルナリアの表情変化はまだ薄い。
- 章数が少なく、1回の遊びとしては短い。

### 次の改善候補

1. 記憶DB、プロフィール、ガチャ持ち物から能力補正を作る。
2. クリア報酬をガチャチケット、星片、日記候補につなげる。
3. 章数を増やし、分岐エンディングを追加する。
4. クリック操作を含むブラウザE2Eテストを導入する。
5. ルナリアの表情、動き、セリフの演出を選択結果ごとに変える。
