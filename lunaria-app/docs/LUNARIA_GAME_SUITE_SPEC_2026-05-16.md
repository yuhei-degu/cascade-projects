# ルナリア内ゲーム機能 仕様書

作成日: 2026-05-16

## 目的

ルナリアを単なる会話AIではなく、「一緒に遊び、記憶し、成長し、現実の会話へ戻ってくる存在」にする。

ゲームは会話体験の補助ではなく、ルナリアの魅力を増やす第二の入口として扱う。

## 全体方針

- 日本人向け、日本語UIを前提にする。
- 終末世界ゲームは短編探索型として残す。
- 新規ゲーム群は、ルナリアの記憶ステータスや能力ステータスを使う攻略型にする。
- プレイヤーは選択肢を選び、章を突破し、クリアを目指す。
- 失敗しても能力が上がり、繰り返すことで必ず進める設計にする。
- 結果はルナリアとの会話へ持ち帰れるようにする。
- 本番DBや課金にはまだ接続せず、当面は `localStorage` に保存する。

## ゲーム分類

### 1. 短編探索型

代表: `終末世界`

役割:
- 雰囲気、演出、ルナリアとの距離感を楽しむ。
- 1プレイを短くする。
- クリア結果を会話に持ち帰る。

特徴:
- 低負荷
- 物語体験重視
- 選択肢は多すぎない
- 失敗より余韻を重視

### 2. 攻略型ストーリー

代表: `記憶迷宮ルナリア`

役割:
- クリア目標を持たせる。
- 記憶、共感、洞察、勇気などの能力値を使う。
- 失敗しても育つことで、最終的にクリアできる。

特徴:
- 章構成
- 能力チェック
- 成功で次章へ進行
- 失敗で能力成長
- クリア報告を会話へ送る

### 3. 今後の候補

- `夢境修復士ルナリア`
  - 悪夢、不安、焦りを選択肢でほどく短編攻略。
- `月庭裁判`
  - 記憶の矛盾を証拠として集める推理型。
- `星片クラフト`
  - ゲームや会話で得た星片を使い、ルナリアの能力や部屋を育てる。

現在の章:
- 第一章 忘れられた駅名
- 第二章 硝子の診断書
- 最終章 朝焼けの契約

進行ルール:
- 選択肢ごとに必要能力がある。
- 能力が足りると成功し、次章へ進む。
- 能力が足りないと未突破になるが、対応能力が上がる。
- クリア点を4以上集めて最終章を突破するとクリア。

保存:
- 進行状態: `lunaria_memory_quest_v1`
- 会話報告: `lunaria_memory_quest_last_report_v1`

## 60 Seconds! オマージュに関する扱い

参考にするのはゲーム構造だけにする。

参考にしてよい:
- 制限やリソース管理の緊張感
- 選択肢で状況が変わる構造
- 失敗しても再挑戦したくなる周回性
- 短い判断を重ねるテンポ

避ける:
- 設定、文章、イベント、UI、家族/シェルター構成の類似
- 具体的な名称や演出の模倣
- 作品固有の体験をそのまま移すこと

ルナリア側では、記憶、感情、約束、終末世界、会話帰還を核にする。

## 自己レビュー

### 良い点

- 終末世界と攻略型ゲームの役割が分かれた。
- `/games` を追加したことで、今後ゲームを増やしやすくなった。
- 記憶迷宮は失敗しても進めるため、詰まりにくい。
- クリア後にルナリアへ報告できるため、ゲームと会話が切れない。
- DB未接続なので、開発中に安全に試せる。

### 気になる点

- まだ本物のルナリア記憶DBやガチャ持ち物とは連動していない。
- 章数が少なく、ゲームとしての厚みはMVP段階。
- 能力値や成長量は仮調整。
- 選択肢の演出はまだ静的で、アニメーションや音はない。
- ブラウザ上のクリック操作までは自動テストできていない。

### 改善方針

1. 記憶DB、プロフィール、ガチャ持ち物から初期能力や補正を作る。
2. クリア報酬として、会話テンション、日記候補、星片クラフト素材を付与する。
3. 章を5〜7章に増やす。
4. 選択肢ごとにルナリアの表情、声色、短い演出を変える。
5. 自動テストは静的到達確認だけでなく、状態遷移の検証を増やす。
