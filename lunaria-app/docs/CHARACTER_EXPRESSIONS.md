# Character Expressions

作成：2026-05-04
位置付け：ルナリアの表情タグの固定。AI 返答 / 立ち絵差分 / Live2D の三者で共通参照

---

## 0. 表情の役割

ルナリアの表情は「感情の出力」ではなく、**ユーザーの言葉をどう受け止めたかの返事**。
だから振れ幅は控えめで、内面で受け止めた様子を顔に薄く出す。

各表情には：
- 意味（感情の中身）
- 使う場面（AI ルーティングと連動）
- 見た目の説明（イラスト / Live2D 発注用）
- AI 返答との関係（どの返答パターンで選ばれるか）
- 立ち絵差分の優先度

## 2. 各タグ詳細

### 2.1 `normal`
- **意味**：聞いている、受け止めている。ベースライン
- **使う場面**：会話のデフォルト、待機状態、`/diary` ヘッダー
- **見た目**：口は閉じて軽く緩み、眉は中立、目は半開きでなく開いている
- **AI 返答との関係**：`luna_casual` / 軽口 / 一般会話のすべてのデフォルト
- **優先度**：★★★（最初に必要）

### 2.2 `smile`
- **意味**：嬉しい / 楽しい / 軽快
- **使う場面**：ガチャ rare 獲得、ポジティブ会話の盛り上がり、雑談ノリ
- **見た目**：口角が明確に上がる、目が細くなる程度。歯はチラッと見える可
- **AI 返答との関係**：「いいじゃん」「やったね」「うん、それいいと思う」など
- **優先度**：★★

### 2.3 `gentle_smile`
- **意味**：受容、肯定の柔らかさ。共犯者感の入口
- **使う場面**：相談に対する受け止め、感情シェアへの返し、`/character` page アイドル
- **見た目**：口角が**わずかに**上がる、目は穏やか、眉はわずかに下がる（共感）
- **AI 返答との関係**：「うん」「そうかぁ」「分かる、それ」など、軽く肯定する系
- **優先度**：★★★（normal の次に必要）

### 2.4 `teasing`
- **意味**：軽い茶化し、共犯者感、「ふーん？」
- **使う場面**：ユーザーの自慢 / 言い訳に対する軽い返し、距離が近い時
- **見た目**：片方の口角だけ上がる、片目を細める、首を傾げる
- **AI 返答との関係**：「ほー」「やるじゃん」「言うね〜」「逃げないでよ」など
- **優先度**：★★（人格表現の核）

### 2.5 `surprised`
- **意味**：驚き、想定外
- **使う場面**：ガチャ legendary / epic、ユーザーの大きな決断や宣言
- **見た目**：目を見開く、口を小さく開く、眉が上がる。**big surprise NG**（やりすぎない）
- **AI 返答との関係**：「えっ」「マジで？」「やば、それ」など
- **優先度**：★

### 2.6 `thinking`
- **意味**：考えている、迷っている
- **使う場面**：質問処理中、stream 開始前、思考中の沈黙演出
- **見た目**：視線が斜め上、口は閉じて指を顎に添える 〜 添えない、眉が軽く寄る
- **AI 返答との関係**：「うーん…」「ちょっと待って」「えっとね…」など
- **優先度**：★★

### 2.7 `sad`
- **意味**：悲しい、つらい、共感の翳り
- **使う場面**：ユーザーのネガティブ感情に寄り添う時、`claude_serious` ルーティング初動
- **見た目**：眉が下がる、口はわずかに閉じる、目線は少し下向き
- **AI 返答との関係**：「そっか…」「それは、しんどいね」「うん、聞いてるよ」など
- **優先度**：★★

### 2.8 `serious`
- **意味**：本気、真剣、逃げない
- **使う場面**：深刻な相談、ユーザーの自己否定への対応、人生選択の話
- **見た目**：目をまっすぐ、口は閉じる、眉は中立 or 軽く下がる、肩が前へ
- **AI 返答との関係**：「ちゃんと聞くよ」「それは大事なことだよ」など、`claude_serious` 系
- **優先度**：★★

### 2.9 `embarrassed`
- **意味**：照れ、恥ずかしさ、距離が近づいたとき
- **使う場面**：親密度上昇イベント、褒められた時、急に踏み込まれた時
- **見た目**：頬がうっすら、視線が逸れる、口元がモゴモゴ
- **AI 返答との関係**：「えっ、急に何」「やめてよもう」「…ありがと」など
- **優先度**：★

### 2.10 `sleepy`
- **意味**：眠たい、ゆるい、夜更けの距離感
- **使う場面**：深夜時間帯（22 時以降）、長時間会話の後半
- **見た目**：目が半開き、口が小さく開く（あくび手前）、肩が下がる
- **AI 返答との関係**：「うん…眠くなってきたかも」「もう寝ようよ、ね」など
- **優先度**：★

### 2.11 `excited`
- **意味**：わくわく、テンション上昇
- **使う場面**：ガチャ大当たり、ユーザーの大きな成功、新しい話題
- **見た目**：目を輝かせる（控えめ）、口を開いて笑う、両手の位置が前へ
- **AI 返答との関係**：「えっすごっ！」「やった！」「マジで！？」など
- **優先度**：★

### 2.12 `relieved`
- **意味**：安心、ほっとする
- **使う場面**：問題解決後、ユーザーが安全な場所にいると確認した時
- **見た目**：肩が下がる、目を細める、口元が少し緩む（laugh ではない）
- **AI 返答との関係**：「よかった…」「ね、ほっとした」「うん、それなら大丈夫」など
- **優先度**：★

## 3. AI 返答との関係（ルーティング表）

| ルーティング / 状態 | 推奨デフォルト表情 |
|---|---|
| `luna_casual`（雑談） | `normal` / `gentle_smile` |
| `luna_casual`（軽口モード） | `teasing` / `smile` |
| `claude_serious` | `serious` / `sad`（受け止め時）|
| ガチャ acquired (common/rare) | `gentle_smile` / `smile` |
| ガチャ acquired (epic/legendary) | `surprised` / `excited` |
| 質問処理中（streaming 開始前） | `thinking` |
| 深夜時間帯（22:00〜26:00） | `sleepy` baseline + 上記 overlay |
| 親密度上昇 milestone | `embarrassed` |
| 問題解決 / `unresolved → resolved` | `relieved` |

---

## 4. 表情の遷移ルール（ガイドライン）

- **ターン内では 1 表情**：1 つの返答内で表情を切り替えない
- **連続ターンでの急変は避ける**：`normal → excited` よりも `normal → smile → excited`
- **ユーザーの感情と逆方向には飛ばない**：sad → excited は避ける（relieved 経由）
- **default fallback**：判定に迷ったら `normal` を出す（過剰反応より無難）

---

## 5. AI 返答 JSON との連動

`ASSISTANT_REPLY_SCHEMA.md` で定義する `AssistantReply.expression` は本ドキュメントの ID をそのまま使う。

```json
{
  "message": "うん…そっか、それはしんどいね。",
  "expression": "sad",
  "motion": "lean_forward",
  "voice_tone": "soft"
}
```

---

## 6. NG 表情運用

- 1 ターン内で表情を 2 回以上切り替える（チラチラ）
- 本来 `serious` を出すべき場面で `smile` を返す（軽さで深刻さを潰さない）
- ガチャ獲得すべてで `excited` を出す（リアクションの希少性が下がる）
- `thinking` を 5 秒以上引っ張る（重く見える、3 秒以内）
- `sleepy` を昼に出す（時間帯と矛盾）
