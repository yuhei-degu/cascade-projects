# Lunaria Game Market Lens

Last updated: 2026-05-21

## 目的

Lunaria のゲーム改善は「思いついた機能を足す」のではなく、売れているゲームの強い型を参考にしながら、Lunaria だけの魅力に変換する。

特に見るべき方向は次の3つ。

1. 10秒で状況が分かる短い緊張
2. キャラクターとの関係が次の選択に残る感覚
3. 失敗しても会話・記憶・次回プレイに意味が残る体験

## 参考にする成功パターン

### 1. 短時間で危機が伝わるゲーム

例: サバイバル、拠点防衛、短い選択で成否が変わるゲーム。

Lunaria への変換:

- 最初の画面で「今なにが危ないか」を1文で出す。
- 選択肢には成功報酬と失敗リスクを必ず見せる。
- 1プレイは3から5分で一区切りにする。
- 敗北はゲーム終了ではなく、Lunaria の記憶や態度に残す。

### 2. キャラクター関係で継続するゲーム

例: キャラ育成、親密度、ストーリー分岐、関係性を集めるゲーム。

Lunaria への変換:

- 勝敗よりも「Lunaria があなたをどう覚えたか」を重視する。
- ゲーム後に会話へ戻ったとき、さっきの選択を Lunaria が一言拾う。
- ステータスは数値だけでなく、信頼、警戒、記憶の傷、希望のような感情タグにする。
- プレイヤーの癖を Lunaria が覚えて、次のゲームで軽く刺す。

### 3. 何度も遊ぶ理由があるゲーム

例: ローグライト、デイリー短編、イベント、収集、ランダム事件。

Lunaria への変換:

- 1回ごとに短いが、次回の初期条件が少し変わる。
- 「今日はここまで」が自然に気持ちよくなる。
- 収集物は武器よりも、記憶断片、約束、写真、秘密、傷跡を優先する。
- 毎回違う事件が起きるが、Lunaria の人格はぶれない。

## 実装前スコアカード

新しいゲーム案や会話改善を実装する前に、10点満点で合計50点として評価する。

1. Hook: 最初の10秒で面白そうか
2. Stakes: 選択に怖さ、迷い、報酬があるか
3. Lunaria Fit: Lunaria の会話、記憶、関係性がないと成立しないか
4. Replay: もう一回やる理由があるか
5. Scope: 1から2ファイル程度で検証できるか

判定:

- 40点以上: 実装してよい
- 32から39点: 1つだけ弱点を直してから実装
- 31点以下: 仕様メモで止める。実装しない

## 今の優先ゲーム方向

### A. 終末世界サバイバル

狙い:

短い危機、選択の緊張、Lunaria との関係持ち帰り。

改善優先:

- AI脅威の圧が行動ごとに変わる
- 成功/失敗が次の日の選択に残る
- ゲーム後にチャットへ戻る理由がある
- 「助かった」だけでなく「何を失ったか」が残る

### B. 記憶ステータスRPG

狙い:

Lunaria の記憶、能力、感情タグを使ってクリアを目指す短編RPG。

改善優先:

- 章ごとに目的をはっきり出す
- 敵を倒すだけでなく、説得、逃走、修復、犠牲の選択を入れる
- クリア時に Lunaria の能力や記憶が増える
- 会話でその変化が分かる

### C. 暴走AIからの脱出

狙い:

Lunaria の魅力を「相棒として一緒に判断してくれる存在」に寄せる。

改善優先:

- 敵AIの行動予告を見せ、対策を選ぶ
- Lunaria が助言するが、必ずしも正解ではない
- プレイヤーが Lunaria を信じるか疑うかで分岐する
- 成功すると信頼が増え、失敗すると警戒や傷が残る

## 常時改善ルール

- Lunaria は常に1枠を改善中にする。
- ただし1サイクルで触る主領域は最大2つ。
- 3サイクルに1回は全体確認を入れ、同じ改善をだらだら繰り返さない。
- 失敗が2回続いたら root-cause task にまとめる。
- ユーザーが忙しくても、人間レビュー前に AIレビュー、自動修正、再検証まで進める。

## 次に実装すべき最小改善

1. ゲーム選択画面に「緊張」「関係持ち帰り」「クリア目標」を表示する。
2. 終末世界ゲームの各選択に、成功報酬と失敗時の傷を出す。
3. ゲーム終了後、チャットへ戻す導線に今回の出来事を持たせる。
4. 会話テストに「ゲーム後の記憶を拾う」ケースを追加する。
