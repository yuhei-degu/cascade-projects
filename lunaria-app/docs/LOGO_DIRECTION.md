# Logo Direction

作成：2026-05-04
位置付け：ロゴの方向性 3 案 + 必要なロゴ種の整理。発注 / 自作の前提

---

## 0. ロゴ方針（共通）

- 月モチーフを必ずどこかに含む
- 暗背景でも明背景でも読める
- 装飾過多にしない（フリル / グロー / シャドウは控えめ）
- フォントは「やわらかいセリフ」または「丸ゴシックの細め」
- カラーは midnight navy / moon white / warm gold の 3 色 で完結

---

## 1. ロゴ方向性 3 案

### 案 A. 月と文字を組み合わせた上品ロゴ

#### 1.1 コンセプト
- 三日月 + "Lunaria" の文字組み
- 月が文字の "L" の左横にコンパクトに配置
- 全体に**間（ま）**を作る、上品系

#### 1.2 ビジュアル
```
   ☾  Lunaria
       ────────
       quiet companion
```

- 月：細い三日月、内側に淡いラベンダー
- フォント：明朝寄り、`Noto Serif JP` / `Cormorant Garamond` 系
- タグライン（オプション）：`quiet companion` / `your night, kept`

#### 1.3 用途
- アプリヘッダー
- 公式サイト hero
- プロモーション動画

#### 1.4 利点 / 欠点
- ✅ 上品、文字も読める
- ✅ Web ヘッダーで馴染む
- ❌ アプリアイコン（小サイズ）には適さない（文字が潰れる）

---

### 案 B. 日記・本モチーフを少し入れた知的ロゴ

#### 2.1 コンセプト
- 開いた本（日記）+ その上に月光が差す
- "Lunaria" は本の下にやや小さく
- 知性 / 記憶 / 日記の含意を強める

#### 2.2 ビジュアル
```
       ☾
    ╱──────╲
   │  ╱╲   │   ← 開いた本
   │ ╱  ╲  │
    ╲────╱
     Lunaria
```

- 本：白〜薄藍のページ、開きすぎず
- 月光：ページに向かって淡くスポット
- フォント：`Cormorant Garamond` イタリック

#### 2.3 用途
- 公式サイト「日記機能」セクション
- ストアページの説明用
- ストーリーテリング系の UI

#### 2.4 利点 / 欠点
- ✅ Lunaria の "記憶 + 日記" を視覚的に伝えられる
- ✅ 物語性がある
- ❌ 主用途（ヘッダー / アイコン）には情報量過多

---

### 案 C. シンプルな月アイコン中心のアプリアイコン向けロゴ

#### 3.1 コンセプト
- 1 つの月モチーフだけ（半月 + うっすら全円）
- 文字なしのシンボル
- アプリアイコン / SNS アイコン専用

#### 3.2 ビジュアル
```
    ●           ← 全円（ペールラベンダー薄）
     ◗          ← 半月（midnight navy 上の moon white）
```

- 月：moon white、背景は midnight navy
- 角丸正方形にフィット
- グラデなし、ベタ + 単純シェイプ

#### 3.3 用途
- iOS / Android アプリアイコン
- favicon
- SNS profile アイコン
- ローディングスピナーの中心

#### 3.4 利点 / 欠点
- ✅ どんなサイズでも読める
- ✅ ブランド認識が早い
- ❌ 単独だと「Lunaria」と分からない（A 案との併用前提）

| 用途 | 推奨案 | サイズ | 形式 |
|---|---|---|---|

## 3. 各ロゴの使用ガイドライン

### 3.1 余白
- ロゴの周囲に「月の半径分」の余白を確保
- 詰めて配置しない

### 3.2 背景色
- 暗背景：midnight navy / 黒
- 明背景：moon white / 淡藍
- グラデ背景は避ける（ロゴが沈む）

### 3.3 拡大縮小
- 最小サイズ：A は 100px 以上、C は 32px 以上
- それ以下は配置しない（C で代用）

### 3.4 NG 加工
- 影 / 発光を強くつける
- 月だけ別色にする
- 文字を圧縮する / 引き伸ばす
- ロゴ周りに装飾フレームを足す

## 6. 議論したい論点

1. **タグライン**：英語（`quiet companion`）vs 日本語（`夜の、隣で`）vs なし
2. **A 案のフォント**：明朝 vs やわらかいセリフ vs 細丸ゴシック
3. **C 案の月の向き**：左欠け vs 右欠け（ブランドにとっての「月の進行方向」）
4. **ロゴカラー**：基本は moon white、warm gold は accent でいいか（金が前面に出すぎない）
5. **キャラクターロゴ**：ルナリア立ち絵 + 文字 のロゴを別案として持つか（マスコットロゴ）
