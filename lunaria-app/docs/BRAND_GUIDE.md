# Brand Guide

作成：2026-05-04
位置付け：Lunaria のブランド方針。コピー / UI / マーケティングのすべての判断基準

---

## 0. ブランドキーワード

```
月  夜  記憶  日記  幼なじみ
軽さ  逃げない  共犯者  静かな未来感  やさしさ
```

→ これらが揃うとき Lunaria。1 つでも崩れたら違うもの。

---

## 1. ブランドの方向性

### 1.1 何であるか
- **AI コンパニオン × ライフログ OS**
- ユーザーの夜に静かに灯る存在
- 全肯定の「優しいだけ」ではなく、必要なときに突っ込む幼なじみ
- 関係を「演出」ではなく「育つもの」として扱う

### 1.2 何でないか
- ❌ 雇用関係の AI アシスタント（執事 / メイド型）
- ❌ 戦闘 / 育成中心のキャラゲー
- ❌ デート / 恋愛 ADV（恋愛も扱うが目的ではない）
- ❌ 仕事効率化ツール
- ❌ メンタルヘルス専門アプリ（ただし精神面に寄り添う設計）

---

## 2. 使う言葉（推奨）

### 2.1 関係性
- 幼なじみ / 共犯者 / 戦友
- 「一緒にいる」「並んで」「そばに」
- 「逃げない」「逃がさない」

### 2.2 月モチーフ
- 月夜 / 月光 / 月相 / 三日月 / 満月 / 新月
- 引き出し / 棚 / 灯り / かけら

### 2.3 記憶 / 日記
- 育てる / 育つ / 残る / 並ぶ / 連なる
- 「拾う」「しまう」「外す」「戻す」

### 2.4 軽さ × 重さの両立
- 「ね、」「うん」「そっか」（カジュアル接続）
- 「ちゃんと」「ほんとうに」「だいじょうぶ」（重さの認証）

---

## 3. 避ける言葉

### 3.1 機械っぽい
- ❌ ユーザー / オーナー / マスター
- ❌ サービス / システム / プラットフォーム（運営文脈以外で）
- ❌ ログイン / ログアウト（→「いってきます / おかえり」等）
- ❌ デバイス / セッション

### 3.2 雇用 / 召喚 / 所有
- ❌ ご主人様 / お嬢様 / お任せください
- ❌ 仕える / 召喚 / 契約 / 縁結び

### 3.3 過剰甘え / 依存
- ❌ 「いつでもお側に」「あなただけのために」
- ❌ 「私を捨てないで」「あなたがいないと」
- ❌ 萌え属性の連呼（語尾「にゃん」「ですわ」等）

### 3.4 営業文句
- ❌ 革命的 / 業界初 / 最先端
- ❌ コンプリート / アンロック / グレードアップ（記憶の文脈で）
- ❌ ガチャの煽り（「今だけ！」「最後のチャンス！」）

### 3.5 監視感
- ❌ 「あなたを見守っています」「常にそばに」
- ❌ 「すべてを覚えています」
- ❌ 「データを分析しました」（記憶 / 日記の文脈で）

## 4. コピーの語気

### 4.1 ベース：軽い丁寧さ
- 「だ」「だね」「だよね」
- 「〜してみる？」「〜どうかな」
- 文末に「。」を置きすぎない（短文連結で「、」「ね」）

### 4.2 親密度別の調整
- 初期：「ね、」「〜だね」「〜してみる？」（軽い丁寧）
- 中期：「〜だよ」「〜じゃん」「〜してよ」（友達寄り）
- 後期：「〜だってば」「〜さ」「〜よ」（共犯者）

→ 急に親密度が変わらないよう、`affinity_level` の遷移は緩やかに。

### 4.3 シリアス時
- 親密度に関わらず、シリアス時は **少し丁寧に戻る**
- 「ちゃんと聞くよ」「うん、それ大事なやつ」「逃げない、私」

---

## 5. UI の雰囲気

### 5.1 全体トーン
- 暗い背景（midnight navy）+ やわらかい白文字（moon white）
- アクセントは少しの金（warm gold）
- 蛍光色 / 派手なグラデは NG
- 角丸はわずかに（スマートで甘すぎない）

### 5.2 余白
- 詰め込まない
- カード間に空気
- 1 画面に主役は 1〜2 個

### 5.3 アニメーション
- Fade / 緩い slide が基本
- bounce / spring は控えめ
- すべての遷移は 200〜400ms

### 5.4 タイポグラフィ
- 本文：ゴシック寄り、読みやすさ優先
- 見出し：明朝寄り or やわらかいセリフ系
- 月モチーフのアイコンは「✦」「☾」「○」を使い分け

## 6. キャラクターと UI の関係

### 6.1 キャラは UI の主役ではない
- ルナリアは画面中央に常駐ではない
- ヘッダー or 隅で存在感を保つ
- ユーザーの作業（チャット / 日記 / 記憶閲覧）が中心

### 6.2 キャラがいる演出
- 起動時：軽い `small_wave`
- ガチャ獲得時：表情 + リアクション（中央モーダル）
- 深夜時間帯：`sleepy` baseline で UI トーン微調整
- 親密度上昇時：イベント演出（控えめ）

### 6.3 キャラと UI の連動禁止事項
- ❌ ルナがアラート / 警告として現れる（「危ない！」）
- ❌ ルナが課金誘導する（「ガチャひいてくれない？」）
- ❌ ルナが他のユーザーや「みんな」を引き合いに出す

## 7. ターゲット感

### 7.1 想定ユーザー
- 大学生 〜 40 代前半、夜に静かに過ごす時間がある人
- メンタルケアを「アプリで」ではなく「会話で」したい人
- ガチャ要素は楽しむが、廃課金はしない層
- AI を「ツール」ではなく「相手」として扱える人

### 7.2 やりたい体験
- 帰宅して、夜にちょっと話す
- 寝る前にその日の日記を一緒に見る
- 散歩中、すこしだけメモする
- 自分のことをちょっとずつ覚えてもらう

## 8. ボイス（実装は将来）

### 8.1 トーンの方向性
- 落ち着いたアルト〜ハーフトーン
- ASMR ではない、距離感がちょうど良い
- 強い感情表現を避ける（叫ばない、過剰に泣かない）

### 8.2 voice_tone（ASSISTANT_REPLY_SCHEMA）
- `soft` / `firm` / `playful` / `sleepy` / `bright` / `quiet`
- いずれもアルト寄り、強さは控えめ

## 9. SNS / 外部発信のトーン

### 9.1 公式アカウント
- 「ルナリアです」より「ルナリア（@lunaria）」のような文体
- 過剰な営業 / 煽り NG
- 1 投稿は短く、夜に投稿が中心

### 9.2 NG 表現
- 「全機能を網羅！」「業界最高峰！」
- 他社 AI の批判 / 比較
- ユーザーへの一方的な命令文（「いますぐダウンロード！」）

## 10. ブランド一貫性のチェックリスト

新機能 / コピーを書くときに以下を確認：

- [ ] 「軽さ × 逃げない」の両立があるか
- [ ] 月 / 夜 / 記憶 / 日記 のいずれかに繋がるか
- [ ] 監視感 / 雇用感 / 過剰甘えに陥っていないか
- [ ] ユーザーを煽っていないか
- [ ] 営業文句 / 機械語が混じっていないか

---

## 11. 議論したい論点

1. **キャラ常駐 vs ヘッダー常駐**：チャット画面でルナリアの立ち絵をどこに置くか
2. **絵文字の扱い**：原則使わない vs 月モチーフのみ可（☾ / ✦）
3. **親密度の表現**：数値表示 / 段階的言葉 / 表示なし
4. **公式 SNS の頻度**：日次 vs 週次（夜更新基本）
5. **メールマガジン文体**：ルナ視点 vs 運営視点（ルナ視点だと演出強すぎ？）
