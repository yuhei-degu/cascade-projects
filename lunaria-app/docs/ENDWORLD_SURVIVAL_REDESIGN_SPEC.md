# 終末世界ゲーム v2 再設計仕様

作成日: 2026-05-17
参照元: `C:\Users\yuuve\Downloads\lunaria_endworld_game_redesign_spec.md`
対象: `lunaria-app/app/endworld/page.tsx`

## 1. 結論

旧 `/endworld` は、雰囲気のよい5場面ノベルとしては成立していたが、ゲームとしては弱かった。
今後の終末世界は、以下を満たす中核ゲームとして扱う。

```text
週1回だけ挑む、ルナリアとの短時間サバイバル。
限られた準備と資源で、何日生き延び、どこまで月面施設へ近づけるかを競う。
結果は終末ログとして会話・日記・育成に持ち帰る。
```

## 2. 旧仕様の問題

- 5場面 linear で、1回遊ぶと終わりやすい。
- 勝敗や失敗理由が曖昧。
- 準備で悩む余地が少ない。
- 資源が減る緊張感がない。
- ルナリアに助けられた実感が弱い。
- 結果が日記・記憶・育成へ残る意味が薄い。

## 3. 新しいゲーム体験

プレイヤーは、終末後の静かな世界をルナリアと進む。
目的は「月面施設」へ近づくこと。
毎回完全クリアできなくてもよいが、毎回ログと改善点が残る。

大事にする感情:

- 準備で悩む
- 選択で後悔する
- 資源が減って焦る
- ルナリアに助けられて嬉しい
- 失敗しても次回に活きる
- 結果を日記に残したくなる

## 4. 参考構造

一部だけ `60 Seconds!` 的な構造を参考にする。

参考にする:

- 限られた準備
- 持ち込む物資の選択
- 毎日資源が減る
- ランダム/準ランダムイベント
- リスクとリターンのある選択
- 失敗しても次回に活きる

参考にしない:

- 核シェルター設定
- 家族構成
- 直接的なコピーイベント
- ブラックコメディ調
- UIや絵柄

Lunaria側のモチーフ:

- 月
- 記憶
- ルナリアとの連携
- 終末後の静かな世界
- 月面施設
- AIの身体
- 日記として持ち帰る記録

## 5. MVP仕様

### URL

`/endworld`

### プレイ頻度

本来は週1回。
MVPでは制限はまだ厳密実装しない。

### プレイ時間

3〜5分。

### 1プレイの流れ

```text
1. 準備フェーズ
2. 持ち込みアイテムを3つ選ぶ
3. Day 1〜7の探索/危機イベント
4. 毎日、資源を消費
5. 選択ごとに能力判定
6. 成功/失敗ログを保存
7. 終了判定
8. 終末ログ生成
9. ホームへ持ち帰り、ルナリアに報告
```

## 6. 資源

MVP資源は3つ。

| 資源 | 役割 | 0になった時 |
|---|---|---|
| 食料 | 生存日数を支える基本資源 | ゲーム終了 |
| エネルギー | ルナリアの移動補助、解析、修復に使う | ゲーム終了 |
| 理性 | 恐怖、記憶、孤独に耐える力 | ゲーム終了 |

毎日、食料とエネルギーは原則減る。
イベントによって理性や追加資源が変動する。

## 7. ルナリア能力

MVP能力は5つ。

| 能力 | 役割 |
|---|---|
| 探索 | 物資、道、危険地帯の発見 |
| 分析 | 状況判断、端末解析、危険予測 |
| 修復 | 設備、通信、ルナリア自身の補修 |
| 防衛 | 崩落、襲撃、災害への対応 |
| 共感 | 親密度連携、精神的危機、特殊イベント |

能力は勝敗を決める唯一の要素ではない。
持ち込み、親密度、選択、ランダム性も含めて判定する。

## 8. 持ち込みアイテム

MVPでは3枠だけ持ち込める。

実装済み候補:

- 保存食
- 小型バッテリー
- 修理キット
- 古い地図
- 通信端末
- 防護マント
- 記憶チップ
- 月のしおり

持ち込みで悩めることが重要。
資源を増やすか、ルナリア能力を伸ばすか、リスク対策に寄せるかを選ぶ。

## 9. イベント設計

悪い選択:

```text
A. 探索する
B. 休む
C. 進む
```

良い選択:

```text
A. 危険を承知で補給ステーションに入る
  成功: 食料獲得
  失敗: 理性低下

B. ルナリアに分析させてから判断する
  コスト: エネルギー消費
  成功: 危険回避

C. 物資を諦めて先へ進む
  成功: 距離を稼ぐ
  失敗: 資源不足が近づく
```

選択には必ず以下を持たせる。

- 必要能力
- リスク
- リターン
- 失敗時ペナルティ
- ルナリアの一言

## 10. 判定式

MVPでは以下の簡易式。

```text
判定値 = 関連能力 + 親密度補正 + random(-2〜+3)
成功条件 = 判定値 >= 難易度
```

今後は以下を追加可能。

- アイテム固有補正
- 隠し信頼値
- トラウマ耐性
- ルナリア連携成功
- 大成功/大失敗

## 11. 終了条件

- 食料が0
- エネルギーが0
- 理性が0
- 月面施設到達度が100%
- Day 7終了

結果は3段階。

| 結果 | 条件 |
|---|---|
| 大成功 | 月面施設到達度100% |
| 成功 | 到達度50%以上でDay 7終了、または資源が残っている |
| 失敗 | 資源切れ、到達度不足 |

## 12. 報酬/持ち帰り

ゲーム後に持ち帰るもの。

- 生存日数
- 月面施設到達度
- 終末ログ
- 星片
- 育成素材
- 次回用の改善点
- 日記化用ログ
- ルナリアの最後の一言

MVPでは `localStorage` に保存し、ホーム画面からルナリアへ報告できる。

## 13. 日記・会話連携

終末ログは2種類に分ける。

### factual_record

事実ログ。

例:

```text
今週の終末ログ:
- ルナリアと5日間生き延びた
- 3日目にガラス雨で食料を失った
- 5日目に通信塔を修復した
- 月面施設到達度は62%
```

### emotional_diary

日記向けの感情ログ。

例:

```text
今回は完全な到達ではなかったけれど、前より遠くまで進めた。
ルナリアが危険な場面で手を引いてくれて、ただのゲーム結果より少し記憶に残った。
次は準備を変えて、もう少し遠くまで行きたい。
```

## 14. 他ゲームの扱い

当面はゲームを増やしすぎない。

```text
/games
  /endworld
```

を中心にする。

既存の `memory-quest` と `dream-repair` は消さないが、将来的には終末世界内の特殊イベント/回復イベントとして吸収する方針。
