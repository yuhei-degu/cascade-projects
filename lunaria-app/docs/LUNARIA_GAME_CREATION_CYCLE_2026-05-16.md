# Lunaria Game Creation Cycle 2026-05-16

## 目的

ルナリアに「会話だけではない遊び」を増やし、ゲーム結果を会話へ持ち帰れるようにする。
終末世界は雰囲気探索、追加ゲームはクリアを目指す攻略型として役割を分ける。

## 今回決めた大枠

- ゲーム一覧 `/games` を入口にする。
- 終末世界 `/endworld` は雰囲気・帰還記録・会話報告を重視する。
- 記憶迷宮 `/games/memory-quest` は記憶/共感/洞察/勇気で章を突破する攻略型にする。
- 夢境修復士 `/games/dream-repair` は安定/信頼/洞察で悪夢を修復して朝へ帰る攻略型にする。
- 失敗しても能力が伸び、繰り返せばクリアできる設計にする。
- ゲーム結果は `localStorage` に保存し、ホームの会話画面に持ち帰りカードとして表示する。

## 自己レビュー

### 良い点

- クリア型ゲームが1本から2本に増えた。
- 終末世界と攻略型ゲームの役割が分かれた。
- 失敗しても進むため、短時間プレイで詰まりにくい。
- ゲーム結果を会話へ戻せるため、ルナリアの関係性強化に使える。
- 本番DB、決済、秘密情報に触らず安全に検証できる。

### まだ弱い点

- ルナリア本体の記憶DB、ガチャ所持品、プロフィール値とはまだ連動していない。
- 章数と演出がまだMVPで、長く遊ぶには浅い。
- クリック操作の自動E2Eは未実施。
- クリア報酬がまだ会話カード中心で、星片やガチャ券への連動は未実装。
